# DaVinci Resolve実作業手順: EP002 福岡JGC修行

> **DaVinci Resolveを開き、この文書を上から順に進めるための作業手順。**
>
> 動画の内容・尺・見せ方の理由は [編集メモ.md](./編集メモ.md) を参照する。
> この作品は「シドニーからの一時帰国に、国内線17レグのJGC修行を組み込んだ旅程記録」。  
> 成否を煽る構成や、疲労・体感変化を無理に物語化しない。実際に起きたことを時系列で残す。

---

## はじめに：画面と用語

- **Media Pool**：読み込んだ動画・写真・音源を置く場所
- **Bin**：Media Pool内のフォルダ
- **Timeline**：映像と音を時間順に並べる編集場所
- **Playhead**：現在位置を示す縦線
- **Clip**：タイムライン上の動画・写真・音声1個
- **Aロール**：本人が状況を説明する映像
- **Bロール**：空港、機窓、食事、手元など説明を補う映像
- **ハードカット**：効果を入れず、次の映像へ瞬時に切り替えること
- **Cross Dissolve**：前後の映像が短く重なりながら切り替わること
- **Inspector**：選択したクリップの大きさ、位置、音量などを変えるパネル
- **キーフレーム**：時間の途中で大きさや位置を変えるための印
- **Editページ**：主な編集場所
- **Fairlightページ**：音量調整
- **Colorページ**：色・明るさ調整
- **Deliverページ**：書き出し

# 0. 最初に決める「完成動画の設定」

Resolveを開く前に、今回作る動画の仕様を固定する。EP001のNZ再編集では縦1080×1920・60fpsだったが、**EP002は横3840×2160・30fps**。設定を流用しない。

| 項目 | EP002で使う設定 | 意味 |
|---|---|---|
| 画面方向 | 横16:9 | YouTubeの通常動画 |
| Timeline resolution | `3840 × 2160 Ultra HD` | 4K UHD |
| Timeline frame rate | `30 fps` | 編集タイムラインのfps |
| Playback frame rate | `30 fps` | 編集中の再生fps |
| Pixel aspect ratio | `Square` | 通常のスマホ・Pocket 3映像 |
| 音声 | `48 kHz / Stereo` | YouTube動画の基本設定 |
| 公開用形式 | `MP4 / H.264` | YouTube用の完成ファイル |
| 公開用ビットレート | 約`50,000 Kb/s` | 4K公開版の目安 |

## なぜ30fpsにするか

今回の基本撮影設定が4K/30fpsだから。60fps素材が一部あっても、タイムラインは30fpsのままにする。60fps素材は通常速度でも使えるが、必要なカットだけスロー用として使用する。

**最重要：Timeline frame rateは素材を並べる前に30fpsへ設定する。**  
一度タイムラインへ素材を入れると、後から変更できない場合がある。

# 1. 新規プロジェクトを作り、最初の設定を完了する

## 1-1. 新規プロジェクト

1. DaVinci Resolveを起動
2. 最初の「Project Manager」で `New Project`
3. Project Nameへ `EP002_JGC-Shugyo`
4. `Create`
5. プロジェクトが開いたら、まだ素材を読み込まない

## 1-2. Project Settingsを開く

画面右下の歯車アイコンをクリックする。  
ウィンドウ上部または左側で `Master Settings` を選ぶ。

## 1-3. Timeline Format

`Master Settings → Timeline Format`で、次のとおり設定する。

```text
Timeline resolution：3840 × 2160 Ultra HD
Timeline frame rate：30
Playback frame rate：30
Pixel aspect ratio：Square
```

確認する数字：

- Widthが`3840`
- Heightが`2160`
- `2160 × 3840`にしない
- `1920 × 1080`にしない
- Timeline frame rateとPlayback frame rateが両方`30`

`Video Monitoring`は最初は初期値のままでよい。これは完成動画の解像度を決める欄ではない。

## 1-4. Image Scaling

`Project Settings → Image Scaling`を開く。

基本的には初期値のままでよい。スマホとPocket 3を横16:9で撮影していれば、通常は自動的に画面へ合う。

縦素材や比率の違う素材が混ざった場合は、プロジェクト全体の設定を変えず、後でそのクリップだけInspectorの`Zoom`と`Position`で調整する。

## 1-5. Color Management

`Project Settings → Color Management`を開く。

今回の最初の作品では複雑なカラーマネジメントを組まず、次を基本にする。

```text
Color science：DaVinci YRGB
Timeline color space：Rec.709 Gamma 2.4
Output color space：Rec.709 Gamma 2.4
```

Pocket 3をD-Log Mで撮影した素材がある場合も、この画面で適当に設定を変えない。素材確認後、Colorページで別途変換・補正する。通常色で撮影したスマホ素材やPocket 3素材へ、Log用変換をかけない。

※現在のResolveでTimeline／Output color space欄が表示されない、または初期値がRec.709になっている場合は、そのままでよい。

## 1-6. 音声設定

`Project Settings → Fairlight`または音声設定欄で確認する。

```text
Timeline sample rate：48 kHz
Bus format：Stereo
```

表示場所がバージョンにより異なる場合は、48 kHzの初期値を維持する。LRC、5.1、7.1には変更しない。

## 1-7. 作業ファイルとプロキシの保存先

`Master Settings → Working Folders`で、Cache filesとProxy generation locationを確認する。

推奨フォルダ例：

```text
EP002編集
  01_素材
  02_音源
  03_Resolve_Proxy
  04_Resolve_Cache
  05_書き出し
```

- Proxy generation location：`03_Resolve_Proxy`
- Cache files location：`04_Resolve_Cache`

保存先を変更しなくても編集できるが、素材と同じドライブに十分な空き容量があるか確認する。OneDrive同期中に重くなる場合は、Proxy／CacheだけPC内の同期対象外フォルダへ置いてよい。

## 1-8. 自動保存とバックアップ

上部メニューの`DaVinci Resolve → Preferences → User → Project Save and Load`を開き、利用できる場合は次を有効にする。Windows環境でもメニュー名は`DaVinci Resolve`。

- `Live Save`
- `Project Backups`

バックアップ間隔は初期値でもよい。設定後も、編集終了時には`Ctrl+S`を押す。

## 1-9. 設定を保存する

1. 右下の`Save`
2. もう一度右下の歯車を開く
3. 次の4項目だけ再確認

```text
3840 × 2160
30 fps
30 fps
Square
```

ここまで終わってから素材を読み込む。

## 1-10. 最初の素材読み込み時に質問が出たら

30fps以外の素材を最初に読み込むと、次のような確認が出る場合がある。

```text
Change Project Frame Rate?
```

今回の設定を30fpsで維持するため、**ChangeではなくDon't Changeを選ぶ。**

## 1-11. タイムラインを作る

1. `File → New Timeline`
2. Timeline Name：`EP002_MASTER_4K30`
3. `Use Project Settings`をオン
4. `Create`
5. Media Poolのタイムラインを右クリック → `Timeline Settings`
6. 次を確認

```text
Use Project Settings：オン
Resolution：3840 × 2160
Frame rate：30
```

- [ ] 横16:9
- [ ] 3840×2160
- [ ] Timeline 30fps
- [ ] Playback 30fps
- [ ] Pixel aspect ratioはSquare
- [ ] 音声48 kHz／Stereo
- [ ] Live Save／Project Backupsを確認
- [ ] Proxy／Cacheの保存先を確認
- [ ] タイムライン名は`EP002_MASTER_4K30`

# 2. Media Poolを見やすく整理する

## 最初に知っておくこと

Windowsで素材をフォルダ分けしていても、`Import Media`でファイルをまとめて選ぶと、**フォルダ構造は引き継がれず、素材だけが現在のBinへ入る**ことがある。

Resolve内のフォルダは`Bin`と呼ぶ。  
Media Pool内でクリップをBinへ移動しても、Windows上の元ファイルは移動・削除・改名されない。Resolveプロジェクト内の整理だけが変わる。

---

## 2-1. 既に素材だけを読み込んだ場合

**タイムライン編集を始めている場合は、素材を削除・再読込しない。** 現在のクリップをBinへ振り分ける。タイムラインとのリンクは維持される。

### まず表示をList Viewへ変える

1. Editページ左上の`Media Pool`を開く
2. Media Pool上部のList Viewアイコンをクリック
3. `Clip Name`列の見出しをクリック
4. 日付・ファイル名の昇順にする  
   逆順になったら、もう一度`Clip Name`をクリック

今回のファイル名は日付から始まるため、Clip Name順でほぼ撮影順になる。

表示しておくと便利な列：

- Clip Name
- Date Created
- Duration
- Resolution
- FPS
- Audio Ch

列が多すぎる場合は、列名の行を右クリックし、不要な列を非表示にする。

### 親Binを作る

Media Pool左側の`Master`を右クリック → `Add Bin`。次を作る。

```text
00_OP候補
01_Day0_Sydney-日本
02_Day1
03_Day2
04_Day3_国内線
05_SakuraLounge
06_JL51_Business
07_Sydney帰着
08_帰宅後_数字とまとめ
09_写真
10_BGM
11_SE
12_ルート図
90_Timeline
99_未分類
```

タイムライン`EP002_MASTER_4K30`は`90_Timeline`へ移動する。映像素材とタイムラインが混ざらなくなる。

### Dayの中へレグ別Binを作る

Day1〜Day3を右クリック → `Add Bin`で、必要なレグだけ子Binを作る。

```text
02_Day1
  L01_HND-FUK
  L02_FUK-KMI
  L03_KMI-FUK
  L04_FUK-KMI
  L05_KMI-FUK
  Day1_食事・ホテル

03_Day2
  L06〜L12
  Day2_食事・ホテル

04_Day3_国内線
  L13〜L17
  国際線へ移動
```

フォルダ名の先頭を`L01`、`L02`のように2桁へ統一すると、Resolve内でもレグ順に並ぶ。

### クリップをまとめて移す

1. `Master`または素材が平置きされたBinを開く
2. Clip Name順にする
3. 同じ日・同じレグの最初のクリップをクリック
4. `Shift`を押しながら最後のクリップをクリック
5. 選択された一群を、左側の該当Binへドラッグ
6. 次のレグも同様に繰り返す

離れた複数クリップだけを選ぶ場合は、`Ctrl`を押しながらクリックする。

### 日付で絞り込んでから移す

素材数が多い場合は、Media Poolの検索欄を使う。

例：

```text
20260819
20260820
20260821
20260822
```

1. 検索欄へ日付を入力
2. その日の素材だけになったことを確認
3. List ViewでClip Name順にする
4. 必要な範囲をShift選択
5. 対応するDayまたはレグBinへ移す
6. 検索欄を消して次の日へ進む

ファイル名に`L01`などのレグ番号が入っている場合は、日付ではなく`L01`で検索するとさらに早い。

### 最初から完璧に分けなくてよい

撮影直後は、まず次の5分類だけでもよい。

```text
Day0
Day1
Day2
Day3
写真・音源
```

粗編集で使う素材が分かってから、採用素材だけをレグ別Binへ細分化してもよい。200本すべてを細かく整理してから編集を始める必要はない。

## 2-2. 次回、Windowsのフォルダ構造をそのままBinにする方法

通常の`Import Media`ではなく、**MediaページのMedia Storageからフォルダを読み込む**。

1. 画面下部の`Media`ページを開く
2. 左上の`Media Storage`で素材の親フォルダを探す
3. Media Pool左側の`Master`または読み込み先Binを表示
4. Media Storage側の親フォルダを右クリック
5. 次の名称に近いコマンドを選ぶ

```text
Add Folder and SubFolders into Media Pool (Create Bins)
```

Resolveのバージョンによっては、次のように表示される。

```text
Add Folder and SubFolders into Media Pool (as Folders)
```

または、Media Storageの親フォルダをMedia Pool左側のFolder Viewへドラッグする。  
この方法なら、Windows側の親フォルダ・子フォルダが、Resolve内でも親Bin・子Binとして作成される。

### 注意

- `Add Folder into Media Pool`：選んだフォルダ直下の素材だけ。子フォルダを無視することがある
- `Add Folder and SubFolders into Media Pool`：子フォルダの素材も入るが、表示される選択肢によっては1つのBinへ平置き
- `Create Bins`または`as Folders`付き：フォルダ階層をBinとして維持

**今回のようにフォルダ構造を残したい場合は、`Create Bins`／`as Folders`付きの方を選ぶ。**

すでに同じ素材を読み込んで編集を始めている場合は、この方法で再読込するとMedia Pool内で重複する可能性がある。現在のEP002では再読込せず、2-1の方法で整理する。

## 2-3. Icon ViewとList Viewの使い分け

### List View

次の作業向け：

- 日付・ファイル名順に並べる
- 解像度やfpsを確認する
- 大量の素材をまとめて選ぶ
- レグ別Binへ振り分ける

### Icon View

次の作業向け：

- 映像内容をサムネイルで探す
- 良い表情・機窓・食事を目で選ぶ
- 冒頭候補を比較する

整理するときはList View、映像を選ぶときはIcon Viewに切り替える。

Icon ViewではSortメニューを`Clip Name`にすると、日付ファイル名順を維持できる。`Custom`にするとサムネイルを好きな順番へ手動配置できるが、今回の基本は`Clip Name`順を使う。

## 2-4. 採用候補を色とFlagで区別する

Bin分けとは別に、素材の状態を印で管理する。

おすすめ：

```text
青：Aロール
緑：Bロール採用候補
黄：冒頭候補
赤：個人情報・他人の顔の確認が必要
Flagなし：未確認
```

操作：

1. クリップを右クリック
2. `Clip Color`または`Flag`
3. 決めた色を選ぶ

色の意味を途中で変えない。  
削除候補でも、撮影直後はMedia Poolから消さず、`99_未分類`または専用の不採用候補Binへ移す。

# 3. タイムラインのトラックを準備する

セクション1-11で作った`EP002_MASTER_4K30`を開く。新しいタイムラインをもう一度作る必要はない。

トラックは次の役割に固定する。

```text
V4：章タイトル・レグカウンター・場所時刻
V3：ルート図・写真・補助グラフィック
V2：Bロール
V1：Aロール／場面の基礎映像

A1：Aロール・撮影素材の音
A2：BGM（Stereo）
A3：環境音
A4：効果音（クリック、シャッター等）
```

BGM用のA2はタイムライン左側を右クリック → Add Track → Stereo。LRC、5.1、7.1は使わない。

# 4. 最初はAロールだけで粗編集する

BGM、色、テロップから始めない。

1. AロールをV1へ時系列で並べる
2. 再生ヘッドを切りたい場所へ置く
3. クリップを選択して `Ctrl+B`（Add Edit）
4. 言い直し、長い無音、重複説明を削除
5. 削除する範囲またはクリップを右クリックし、Ripple Deleteを選んで隙間を詰める
6. 各章の先頭へMarkerを置き、章名を付ける

Aロールの順番：

1. シドニー出発
2. 日本到着
3. 羽田で旅程説明
4. Day1の各地点
5. Day2の各地点
6. Day3と17レグ完了
7. 初サクララウンジ
8. JL51ビジネスクラス
9. シドニー到着
10. 帰宅後の費用・LSP・まとめ

**発言を残す基準**は、場所・時刻・便・次の予定・実際に起きたことが分かるか。画面で既に分かる説明は短くする。

v0の目標は、Aロールだけで旅程が理解できる状態。想定完成尺は12〜14分台だが、素材に合わせて短くしてよい。

# 5. Bロールを重ねる

Aロールの声を残したまま、説明に合う映像をV2へ置く。

例：

```text
Aロール「次は福岡から宮崎です」
V2：出発案内 → 搭乗口 → 機窓
A1：本人の声は継続
```

Bロール1カットの目安：

- 案内表示：1.5〜3秒
- 空港全景：2〜4秒
- 食事：2〜3秒
- 機窓：2〜4秒
- 設備の寄り：1.5〜2.5秒
- 本人のリアクション：2〜4秒

同じ構図を長く見せない。ただし文字を読む映像は、読める長さを確保する。

# 6. 冒頭22秒を最後に作る

本編の粗編集が完成してから、良い素材を複製して先頭へ置く。撮影順ではなく「今回の旅程の要約」にする。

| 時間 | V1/V2の映像 | V4の文字 | 音 |
|---|---|---|---|
| 0:00-0:03 | 搭乗案内または機体 | なし | 空港環境音／チャイム |
| 0:03-0:06 | シドニー空港＋キャリー | `SYDNEY → JAPAN` | BGM開始 |
| 0:06-0:09 | 搭乗口・機窓の短い連続 | `01/17 → 06/17 → 12/17 → 17/17` | 数字ごとにクリック |
| 0:09-0:12 | 宮崎6回目の時計 | `FUK ⇄ KMI × 6` | 現地音を一瞬残す |
| 0:12-0:15 | Day2の搭乗案内または時計 | `DAY 2 / 7 LEGS` | BGM継続 |
| 0:15-0:18 | サクララウンジ入口 | `FIRST SAKURA LOUNGE` | BGMを少し下げる |
| 0:18-0:21 | ビジネスクラス座席 | `JAL BUSINESS TO SYDNEY` | BGMを戻す |
| 0:21-0:22 | 機窓 | なし | タイトルへつなぐ |

## 0:06〜0:09「レグカウンターが増える＋クリック音」

これは自動計算ではなく、**短いText+を4個並べる**。

1. Effects → Titles → Text+をV4へ置く
2. InspectorのTextへ `01 / 17`
3. フォント、位置、背景を整える
4. そのText+を `Alt` を押しながら右へドラッグして複製
5. 複製を4個作り、それぞれ `06 / 17`、`12 / 17`、`17 / 17` に変更
6. 4個が合計3秒になるよう、各クリップを約0.75秒にする
7. クリック音をMedia Poolへ読み込みA4へ置く
8. 各Text+の先頭にクリック音の波形先頭を合わせる
9. クリック音4個を選択し、Inspector → Audio → Volumeをまず `-15 dB`
10. BGMと一緒に再生し、強ければ `-18〜-22 dB`へ下げる


# 8. 切り替え（トランジション）

## 基本：何も入れない

同じ場所・同じ時間・同じ動作はハードカット。クリップ同士を隙間なく置くだけ。

## Cross Dissolve

場所や時間が大きく変わる章境目だけ。

1. Effects → Video Transitions
2. Cross Dissolveを検索
3. 2つのクリップの境界へドラッグ
4. 長さを6〜12フレーム（30fpsで0.2〜0.4秒）

置けない場合は、前のクリップ末尾と次のクリップ冒頭に重ねる余分な映像がない。両端を少し短くしてから置く。

## Dip to Color Dissolve

夜→朝、最後→黒画面など、大きな時間経過だけ。0.4〜0.8秒。

ズーム、回転、Glitch、Warpなどは基本的に使わない。

# 9. 1カットだけアップする／徐々にアップする

## 1カットだけ大きくする

**タイムライン全体やAdjustment Clipを選ばず、対象クリップ1個だけを選ぶ。**

1. Editページで対象クリップをクリック
2. 白い枠がそのクリップだけに付いたことを確認
3. Inspector → Video → Transform
4. Zoomを `1.00 → 1.10` などへ変更
5. Position X/Yで重要部分を中央へ
6. 前後のクリップへ移動し、変わっていないことを確認

同じ素材が長く、途中だけアップしたい場合：

1. アップ開始位置へPlayhead
2. クリップを選び `Ctrl+B`
3. アップ終了位置でも `Ctrl+B`
4. 真ん中にできたクリップだけ選択
5. InspectorのZoom/Positionを変更

## 同じカット内で徐々にアップ

1. 対象クリップを選択
2. Inspector → Video → Transform
3. Playheadをクリップ先頭へ
4. Zoom右側のひし形をクリック（最初のキーフレーム）
5. Zoomを `1.00`
6. Playheadをクリップ末尾へ
7. Zoomを `1.08〜1.15` に変更  
   通常は自動で2個目のキーフレームが入る
8. 再生して速すぎればZoom差を小さくする

必要ならPosition X/Yにも同じ方法でキーフレームを付ける。顔や料理が画面外へ出ないよう確認する。

# 10. 写真を入れる

写真はV2またはV3へ置き、1枚2〜4秒。

- 基本：ハードカット
- 写真群の最初だけ：白フラッシュ＋シャッター音
- 連続写真：毎回フラッシュさせず、必要ならシャッター音だけ

白フラッシュ：

1. Effects → Generators → Solid ColorをV3へ
2. Inspectorで白
3. 長さを4〜6フレーム
4. Opacityを70〜85%から調整
5. A4にシャッター音を合わせる

# 11. テロップと字幕

## 基本デザイン

- フォントは読みやすいゴシック体1種類
- 白文字＋黒い影、または半透明の黒背景
- 強調色は1色
- 1画面2行まで
- 画面端へ寄せすぎない
- 場所・時刻は左下、レグカウンターは右上

Effects → Titles → Text+をV4へ置き、Inspectorで文字・位置・大きさを設定する。最初の1個を完成させてから複製し、表記だけ変える。

発言を全文字幕にせず、必要な情報だけ表示する。自動字幕機能が表示される場合も、無料版・バージョンによって利用可否が違うため、必須にはしない。

# 12. 個人情報・他人の顔をぼかす

初心者向けにはColorページのWindow＋Trackerを使う。

1. 対象クリップを選択
2. Colorページへ
3. 新しいSerial Nodeを追加（`Alt+S`）
4. Blurパレットでぼかしを強くする
5. Windowパレットで丸または四角を選ぶ
6. 搭乗券、予約番号、顔などへWindowを合わせる
7. Trackerパレットで前後へ追跡
8. 全区間再生し、対象から外れていないか確認

追跡が外れる箇所は、その位置でWindowを手動調整する。搭乗券、会員番号、QRコード、予約番号、PC・スマホ画面は必ず確認する。

# 13. 音声・BGM・効果音

## BGMを入れる

1. MP3またはWAVをMedia Poolへ読み込む
2. A2（Stereo）へ置く
3. Inspector → Audio → Volumeをまず `-18 dB`
4. 会話中は `-22〜-28 dB` を目安にさらに下げる
5. 無言の景色では少し戻す

SpotifyやApple Musicのオフライン保存曲は使わない。使用許諾とクレジット条件を確認し、`公開情報.md`へ記録する。

## BGMを徐々に下げる

1. BGMクリップを選択
2. Inspector → Audio → Volumeのひし形をクリック
3. 下げ始めにキーフレーム
4. 0.5〜1秒後へPlayheadを移動
5. Volumeを下げる
6. 会話終了後は逆の2点で戻す

クリップ端のフェードハンドルを内側へドラッグしても、開始・終了を自然にできる。

## Fairlightで最終確認

1. Fairlightページへ
2. Mixerを表示
3. 声、環境音、BGM、SEの順に確認
4. 本人の声のピークは概ね `-6〜-3 dB`
5. Bus 1が0 dBを超えないようにする
6. 最後にイヤホンとPCスピーカーで確認

公開用の全体ラウドネスは `-14〜-16 LUFS` を参考にする。数値だけに合わせず、声が常に明瞭かを優先する。

# 14. 色・明るさを合わせる

Colorページで、まずカメラごとの違和感を減らす。

1. 明るさ
2. ホワイトバランス（黄・青、緑・マゼンタ）
3. コントラスト
4. 彩度

スマホとPocket 3を完全一致させる必要はない。空港、夜の機内、ラウンジをまとめて一括補正せず、違和感のあるクリップだけ直す。強いLUTやフィルターを全素材へ一括適用しない。
