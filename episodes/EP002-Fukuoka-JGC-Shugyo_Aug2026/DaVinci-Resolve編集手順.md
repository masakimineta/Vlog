# DaVinci Resolve実作業手順: EP002 福岡JGC修行

> **DaVinci Resolveを開き、この文書を上から順に進めるための作業手順。**
>
> 動画の内容・尺・見せ方の理由は [編集メモ.md](./編集メモ.md) を参照する。
> この作品は「シドニーからの一時帰国に、国内線17レグのJGC修行を組み込んだ旅程記録」。  
> 成否を煽る構成や、疲労・体感変化を無理に物語化しない。実際に起きたことを時系列で残す。

---

## 全体の流れ

3 つの版を順に作る。**一度で完成させようとしない。**

| 版 | やること | やらないこと |
|---|---|---|
| **v0** | Aロールだけ並べて、旅程が追えるか確認する | BGM・色・テロップ |
| **v1** | Bロール、レグカウンター、ルート図、BGM、基本の色合わせ | 細かいテンポ調整 |
| **v2** | テンポと音量の修正、ぼかし、表記の照合 | 新しい演出の追加 |

この文書は 1〜17 の順に並んでいるが、**§4 まで進んだら一度 v0 を書き出して全編を見る**。
そこで構成の問題が見つかれば、Bロールや色を作り込む前に直せる。

各版で具体的に何を入れるかは §15、書き出し設定は §16 にある。

---

## はじめに：画面と用語

- **Media Pool**：読み込んだ動画・写真・音源を置く場所
- **Bin**：Media Pool内のフォルダ
- **Timeline**：映像と音を時間順に並べる編集場所
- **Playhead**：現在位置を示す縦線
- **Clip**：タイムライン上の動画・写真・音声1個
- **Aロール**：本人が状況を説明する映像
- **Bロール**：空港、機窓、食事、手元など説明を補う映像
- **ハードカット**：効果を入れず、次の映像へ瞬時に切り替えること
- **Cross Dissolve**：前後の映像が短く重なりながら切り替わること
- **Inspector**：選択したクリップの大きさ、位置、音量などを変えるパネル
- **キーフレーム**：時間の途中で大きさや位置を変えるための印
- **Editページ**：主な編集場所
- **Fairlightページ**：音量調整
- **Colorページ**：色・明るさ調整
- **Deliverページ**：書き出し

# 1. プロジェクトを作る

1. Resolveを起動
2. Project Managerで「New Project」
3. 名前を `EP002_JGC-Shugyo`
4. 右下の歯車「Project Settings」を開く
5. Master Settingsで次を設定

```text
Timeline resolution：3840 × 2160 Ultra HD
Timeline frame rate：30
Playback frame rate：30
```

6. Save

**フレームレートは素材を並べる前に決める。** 今回は横16:9、4K、30fpsで統一する。スマホもPocket 3も横向き素材を使用する。

## 保存とバックアップ

Project Settings → Project Save and Loadで、利用できる場合は以下を有効にする。

- Live Save
- Project Backups

編集終了時には `Ctrl+S` も押す。

# 2. 素材を読み込み、Binを作る

MediaページまたはEditページのMedia Poolで、次のBinを作る。

```text

02_Day1
03_Day2
04_Day3_国内線

09_写真
10_BGM
11_SE

99_不採用候補
```

素材整理スクリプトで作ったL01〜L17フォルダは、対応するDayのBin内へ読み込む。

1. Media Poolの空白を右クリック
2. Import Media
3. 日付・レグ別フォルダを選択
4. 「Change Project Frame Rate?」が出ても、設定済みの30fpsを維持する
5. 素材を数本開き、映像と音が正常か確認

## PCが重い場合

素材をMedia Poolで選択 → 右クリック → Generate Proxy Media。  
作成後、Playback → Proxy Handling → Prefer Proxiesを選ぶ。最終書き出しは通常、元素材を参照する。

# 3. タイムラインとトラックを作る

1. File → New Timeline
2. 名前を `EP002_MASTER_4K30`

トラックは次の役割に固定する。


# 4. 最初はAロールだけで粗編集する

BGM、色、テロップから始めない。

1. AロールをV1へ時系列で並べる
2. 再生ヘッドを切りたい場所へ置く
3. クリップを選択して `Ctrl+B`（Add Edit）
4. 言い直し、長い無音、重複説明を削除
5. 削除後の隙間を選び、Backspaceまたはリップル削除で詰める
6. 各章の先頭へMarkerを置き、章名を付ける

Aロールの順番：

1. シドニー出発
2. 日本到着
3. 羽田で旅程説明
4. Day1の各地点
5. Day2の各地点
6. Day3と17レグ完了
7. 初サクララウンジ
8. JL51ビジネスクラス
9. シドニー到着
10. 帰宅後の費用・LSP・まとめ

**発言を残す基準**は、場所・時刻・便・次の予定・実際に起きたことが分かるか。画面で既に分かる説明は短くする。

v0の目標は、Aロールだけで旅程が理解できる状態。想定完成尺は12〜14分台だが、素材に合わせて短くしてよい。

# 5. Bロールを重ねる

Aロールの声を残したまま、説明に合う映像をV2へ置く。

例：

```text
Aロール「次は福岡から宮崎です」
V2：出発案内 → 搭乗口 → 機窓
A1：本人の声は継続
```

Bロール1カットの目安：

- 案内表示：1.5〜3秒
- 空港全景：2〜4秒
- 食事：2〜3秒
- 機窓：2〜4秒
- 設備の寄り：1.5〜2.5秒
- 本人のリアクション：2〜4秒

同じ構図を長く見せない。ただし文字を読む映像は、読める長さを確保する。

# 6. 冒頭22秒を最後に作る

本編の粗編集が完成してから、良い素材を複製して先頭へ置く。撮影順ではなく「今回の旅程の要約」にする。

| 時間 | V1/V2の映像 | V4の文字 | 音 |
|---|---|---|---|
| 0:00-0:03 | 搭乗案内または機体 | なし | 空港環境音／チャイム |
| 0:03-0:06 | シドニー空港＋キャリー | `SYDNEY → JAPAN` | BGM開始 |
| 0:06-0:09 | 搭乗口・機窓の短い連続 | `01/17 → 06/17 → 12/17 → 17/17` | 数字ごとにクリック |
| 0:09-0:12 | 宮崎6回目の時計 | `FUK ⇄ KMI × 6` | 現地音を一瞬残す |
| 0:12-0:15 | Day2の本人または案内表示 | `3 DAYS / 17 LEGS` | BGM継続 |
| 0:15-0:18 | サクララウンジ入口 | `FIRST SAKURA LOUNGE` | BGMを少し下げる |
| 0:18-0:21 | ビジネスクラス座席 | `JAL BUSINESS TO SYDNEY` | BGMを戻す |
| 0:21-0:22 | 機窓 | なし | タイトルへつなぐ |

## 0:06〜0:09「レグカウンターが増える＋クリック音」

これは自動計算ではなく、**短いText+を4個並べる**。

1. Effects → Titles → Text+をV4へ置く
2. InspectorのTextへ `01 / 17`
3. フォント、位置、背景を整える
4. そのText+を `Alt` を押しながら右へドラッグして複製
5. 複製を4個作り、それぞれ `06 / 17`、`12 / 17`、`17 / 17` に変更
6. 4個が合計3秒になるよう、各クリップを約0.75秒にする
7. クリック音をMedia Poolへ読み込みA4へ置く
8. 各Text+の先頭にクリック音の波形先頭を合わせる
9. クリック音4個を選択し、Inspector → Audio → Volumeをまず `-15 dB`
10. BGMと一緒に再生し、強ければ `-18〜-22 dB`へ下げる

```text
V4：01/17｜06/17｜12/17｜17/17
A4： click｜click｜ click｜ click
```

派手なアニメーションは不要。必要ならText+のInspector → Settings → Zoomのキーフレームで、各数字を `0.95 → 1.00` とごく小さく動かす。

## タイトル

0:22前後から8〜10秒。

```text
一時帰国でJGC修行
3日間・国内線17レグ
```

背景は静止画ではなく、機窓・歩行・空港全景などゆっくり動く映像を使う。

# 8. 切り替え（トランジション）

## 基本：何も入れない

同じ場所・同じ時間・同じ動作はハードカット。クリップ同士を隙間なく置くだけ。

## Cross Dissolve

場所や時間が大きく変わる章境目だけ。

1. Effects → Video Transitions
2. Cross Dissolveを検索
3. 2つのクリップの境界へドラッグ
4. 長さを6〜12フレーム（30fpsで0.2〜0.4秒）

置けない場合は、前のクリップ末尾と次のクリップ冒頭に重ねる余分な映像がない。両端を少し短くしてから置く。

## Dip to Color Dissolve

夜→朝、最後→黒画面など、大きな時間経過だけ。0.4〜0.8秒。

ズーム、回転、Glitch、Warpなどは基本的に使わない。

# 9. 1カットだけ加工する（アップ・スロー）

## 1カットだけ大きくする

**タイムライン全体やAdjustment Clipを選ばず、対象クリップ1個だけを選ぶ。**

1. Editページで対象クリップをクリック
2. 白い枠がそのクリップだけに付いたことを確認
3. Inspector → Video → Transform
4. Zoomを `1.00 → 1.10` などへ変更
5. Position X/Yで重要部分を中央へ
6. 前後のクリップへ移動し、変わっていないことを確認

同じ素材が長く、途中だけアップしたい場合：

1. アップ開始位置へPlayhead
2. クリップを選び `Ctrl+B`
3. アップ終了位置でも `Ctrl+B`
4. 真ん中にできたクリップだけ選択
5. InspectorのZoom/Positionを変更

## 同じカット内で徐々にアップ

1. 対象クリップを選択
2. Inspector → Video → Transform
3. Playheadをクリップ先頭へ
4. Zoom右側のひし形をクリック（最初のキーフレーム）
5. Zoomを `1.00`
6. Playheadをクリップ末尾へ
7. Zoomを `1.08〜1.15` に変更  
   通常は自動で2個目のキーフレームが入る
8. 再生して速すぎればZoom差を小さくする

必要ならPosition X/Yにも同じ方法でキーフレームを付ける。顔や料理が画面外へ出ないよう確認する。

## 60fpsで撮った素材をスローにする

`撮影計画.md` で「スローにする明確な目的があるショットだけ4K/60fps」としている素材の扱い。

**60fpsのまま置いても自動ではスローにならない。** 30fpsのタイムラインに置くと等速で再生される。
スローにする操作を自分で行う。

1. Media Poolで対象クリップのFrame Rateが60になっていることを確認
2. タイムライン上のクリップを右クリック → Change Clip Speed
3. Speedを `50%` にする
4. 再生して長さと動きを確認

**50%を基準にする。** 60fpsの素材を半分の速度にすると、30fpsのタイムラインで元のコマを
1枚ずつ使い切るため、フレームを作り足さずに滑らかになる。

- 50%より遅くしたい場合は、Inspector → Video → Retime and Scaling → Retime Processを
  `Optical Flow` にすると滑らかになるが、処理が重くなる。`Nearest` のままでも実用上は足りる
- **スローにすると音も一緒に間延びする。** スローで使うのはBロール（音を使わないカット）に限る。
  どうしても音を残す場合は、クリップを右クリック → Link Clips を外してから映像だけ変速する
- 速度を変えるとクリップが長くなる。後ろが押されるので、変速してから前後を詰める

30fpsで撮ったものを後からスローにはしない。コマが足りず、動きが飛んで見える。

# 10. 写真を入れる

写真はV2またはV3へ置き、1枚2〜4秒。

- 基本：ハードカット
- 写真群の最初だけ：白フラッシュ＋シャッター音
- 連続写真：毎回フラッシュさせず、必要ならシャッター音だけ

白フラッシュ：

1. Effects → Generators → Solid ColorをV3へ
2. Inspectorで白
3. 長さを4〜6フレーム
4. Opacityを70〜85%から調整
5. A4にシャッター音を合わせる

# 11. テロップと字幕

## 基本デザイン

- フォントは読みやすいゴシック体1種類
- 白文字＋黒い影、または半透明の黒背景
- 強調色は1色
- 1画面2行まで
- 画面端へ寄せすぎない
- 場所・時刻は左下、レグカウンターは右上

Effects → Titles → Text+をV4へ置き、Inspectorで文字・位置・大きさを設定する。最初の1個を完成させてから複製し、表記だけ変える。

発言を全文字幕にせず、必要な情報だけ表示する。自動字幕機能が表示される場合も、無料版・バージョンによって利用可否が違うため、必須にはしない。

# 12. 個人情報・他人の顔をぼかす

初心者向けにはColorページのWindow＋Trackerを使う。

1. 対象クリップを選択
2. Colorページへ
3. 新しいSerial Nodeを追加（`Alt+S`）
4. Blurパレットでぼかしを強くする
5. Windowパレットで丸または四角を選ぶ
6. 搭乗券、予約番号、顔などへWindowを合わせる
7. Trackerパレットで前後へ追跡
8. 全区間再生し、対象から外れていないか確認

追跡が外れる箇所は、その位置でWindowを手動調整する。搭乗券、会員番号、QRコード、予約番号、PC・スマホ画面は必ず確認する。

# 13. 音声・BGM・効果音

## BGMを入れる

1. MP3またはWAVをMedia Poolへ読み込む
2. A3（Stereo）へ置く
3. Inspector → Audio → Volumeをまず `-18 dB`
4. 会話中は `-22〜-28 dB` を目安にさらに下げる
5. 無言の景色では少し戻す

SpotifyやApple Musicのオフライン保存曲は使わない。使用許諾とクレジット条件を確認し、`公開情報.md`へ記録する。

## BGMを徐々に下げる

1. BGMクリップを選択
2. Inspector → Audio → Volumeのひし形をクリック
3. 下げ始めにキーフレーム
4. 0.5〜1秒後へPlayheadを移動
5. Volumeを下げる
6. 会話終了後は逆の2点で戻す

クリップ端のフェードハンドルを内側へドラッグしても、開始・終了を自然にできる。

## Fairlightで最終確認

1. Fairlightページへ
2. Mixerを表示
3. 声、環境音、BGM、SEの順に確認
4. 本人の声のピークは概ね `-6〜-3 dB`
5. Bus 1が0 dBを超えないようにする
6. 最後にイヤホンとPCスピーカーで確認

公開用の全体ラウドネスは `-14〜-16 LUFS` を参考にする。数値だけに合わせず、声が常に明瞭かを優先する。

# 14. 色・明るさを合わせる

Colorページで、まずカメラごとの違和感を減らす。

1. 明るさ
2. ホワイトバランス（黄・青、緑・マゼンタ）
3. コントラスト
4. 彩度

スマホとPocket 3を完全一致させる必要はない。空港、夜の機内、ラウンジをまとめて一括補正せず、違和感のあるクリップだけ直す。強いLUTやフィルターを全素材へ一括適用しない。
