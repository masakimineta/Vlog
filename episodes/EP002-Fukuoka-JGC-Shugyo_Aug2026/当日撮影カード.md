# 当日撮影カード: EP002 福岡JGC修行

> 目的：現地ではこのファイルだけを見る。長い台本を覚えない。
>
> 各地点で必ず撮るのは **①場所 ②証拠 ③自分の一言** の3種類。
> 1本につき録画開始後2秒待ち、5〜8秒固定し、終了前も2秒待つ。

## この動画の記録範囲

**シドニー出発から一時帰国、国内線17レグ、サクララウンジ、ビジネスクラス、シドニー帰着までを時系列で記録する。**

参考動画から取り入れるのは次の4点だけ。

1. 冒頭で結末の一部を見せる
2. 景色だけでなく、その場の本人の言葉を残す
3. その場所の音を単独で録る
4. 1日の終わりに当日の実績と翌日の予定を話す

派手なトランジションや120fps撮影は必須ではない。まず旅程を説明する素材を欠かさない。

---

## 撮影設定

- **基本：横16:9、4K / 30fps**
- シドニー空港〜日本到着：スマホを横向きで撮影
- 日本到着後：DJI Osmo Pocket 3を主機材にする
- スマホはPocket 3を出しにくい場面と予備用
- スローで使うと決めた短い素材のみ：4K / 60fps
- Shorts用の縦素材は、本編用の横素材を撮り終えた後に別テイクで撮る
- 録画中にスマホを縦横へ回転させない
- レンズ：基本1倍。0.5倍は空港・部屋の全景だけ
- デジタルズームは使わない
- 1ショット：最低5秒
- 他の乗客・係員の顔、搭乗券の個人情報を映しすぎない
- 保安検査・出入国審査は撮影しない
- 店内は撮影前に確認する

## 編集で困らないための3つの癖

3日で約200本撮る。**DaVinci ResolveのMedia Poolに取り込んだとき、どれが何番か分からなくなるのが一番きつい。**
現場で次の3つを守るだけで、編集の最初の数時間が消える。

### 1. 便名表示は「区切り」。必ずそのレグの最初に撮る

5点セットの1本目を**例外なく便名表示から始める**。撮る順番を毎回同じにすれば、
Resolveのタイムラインへ時系列に並べたとき、**便名表示が出てくるたびに次のレグが始まる**と読める。
カチンコの代わりになるので、これだけで200本が17のまとまりに割れる。

- 順番を入れ替えない。**迷ったら便名表示を撮ってから考える**
- 撮り忘れたら、搭乗口の番号でも時計でもいい。**何か1本、区切りになる画を挟む**

### 2. Aロールは録画開始直後に番号を小声で言う

```
（録画開始）→「A008、宮崎」→ 一呼吸 → 本編を話す
```

- 頭の2秒は編集で切るので、**完成には残らない**
- Resolveで字幕または文字起こしを作る場合もこの一言が目印になり、**内容を見るだけでどのAロールか分かる**
- Aロール17本だけでいい。Bロールは便名表示の区切りで判別できる

### 3. 撮り直したら、そのテイクの前に手をかざす

同じ内容を2回撮ったとき、あとで見分けがつかない。
**採用したいテイクの直前に、レンズの前で手を1回振る。** 編集では手が映っているほうを使う。

## 音声（Aロールはこれで決まる）

空港は館内アナウンスとキャリーバッグの音が常に鳴っている。**内蔵マイクだけのAロールは編集で救えない。**

- **Aロールは必ずワイヤレスマイクを襟に付けて撮る**。送信機は口元から15〜20cm
- **風防を付ける**。空調と屋外（宮崎の展望デッキ）で効く
- 録画開始したら、**画面にマイクの接続表示が出ているか5秒だけ確認する**
- 送信機のバッテリーを毎レグ見る。1日7レグは実質フル稼働
- **離陸中はAロールを撮らない**（音が振り切れる）
- マイクを忘れた・使えないときは、**壁際か柱のかげに寄って、声を張らずに近い距離で話す**。
  それも無理なら映像だけ撮り、**その晩ホテルで同じ内容を録り直す**

## Aロールの撮り方（Pocket 3）

**今回の最重要課題はAロールを全レグ撮ること。うまく話す必要はない。**

1. 手すり・カウンター・スーツケースのハンドルに置く
2. 画面を自分に向けて**顔追尾（ActiveTrack）をON**にする。持ち続けなくていい／ピントも自動で追う
3. **イヤホンを付ける**。周囲からは通話に見えるので、人のいる場所でも撮りやすい
4. 録画開始 → 2秒待つ → 話す → 2秒待つ → 停止

- 三脚は広げない。**置いてフレームに入るだけ**なら10秒で始められる
- 歩きながらでもジンバルで安定する。乗り継ぎの移動中にそのまま撮ってよい
- 言い間違えたら止めずに**その文だけ言い直す**

## 毎回の搭乗で撮る「5点セット」

毎レグ、全部で1分以内に終える。

- [ ] **便名表示**：正面から5秒固定
- [ ] **時刻**：時計または案内板を5秒固定
- [ ] **搭乗の証拠**：搭乗口付近の足元／機体／ボーディングブリッジを5秒
- [ ] **機内ディテール**：シートベルト、窓、翼のどれかを5秒
- [ ] **一言**：レグ番号＋区間＋時刻＋次の予定を10秒

一言の型：

> 「これで［数字］本目。［出発地］から［到着地］へ向かいます。出発は［時刻］、到着後は［次の予定］です」

例：

> 「これで8本目。宮崎から福岡へ戻ります。出発は［時刻］、福岡到着後は次の宮崎便へ乗り継ぎます」

毎回うまく話す必要はない。**レグ番号・場所・時刻・次の予定**を残せば編集で使える。

# トラブル時に回すカメラ

遅延・欠航・乗り継ぎ変更が起きたら、案内板を撮ったあと次の4点を話す。

1. 何が起きたか
2. 現在時刻
3. 次便まで何分か
4. どの予定を諦めるか

例：

> 「現在18時40分です。宮崎発が25分遅れていて、福岡到着は21時55分予定になりました。屋台は諦めて、そのままホテルへ向かいます」

他人やスタッフへカメラを向けず、自分と案内表示だけで説明する。
