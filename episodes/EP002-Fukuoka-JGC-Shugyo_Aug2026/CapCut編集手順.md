# はじめに：この文書で使う言葉

**分からない言葉が出てきたら、まずここに戻ってくる。**

## 編集ソフトの画面の話

| 言葉 | 意味 |
|---|---|
| **タイムライン** | 画面の下半分にある作業場所。左から右へ時間が流れる。ここに素材を並べて動画を作る |
| **クリップ** | タイムラインに置いた動画1本ぶんのかたまり。切ると2つのクリップになる |
| **トラック** | タイムラインの「段」。上下に重ねられる。`V1` `V2` は映像の段、`A1` `A2` は音の段。**数字が大きいほど手前（画面の上）に表示される** |
| **再生ヘッド** | いま何秒目を見ているかを示す縦の線。切る位置もここで決まる |
| **Ctrl+B** | 再生ヘッドの位置でクリップを2つに切る（Macは `Cmd+B`）。この動画の編集でいちばん使う操作 |
| **スケール** | 拡大率。`100` が元のまま、`108` なら8％大きい |
| **ミュート** | その音を鳴らさないようにする |
| **波形** | 音の大きさを表すギザギザの絵。音と映像を合わせるときに見る |
| **エクスポート（書き出し）** | 完成した動画を1本のファイルとして保存すること |

## 動画づくりの言葉

| 言葉 | 意味 |
|---|---|
| **素材** | 撮ってきた動画1本1本のこと |
| **カット** | 素材から必要なところだけ切り出した一片 |
| **尺（しゃく）** | 長さのこと。「尺が長い」＝長すぎる |
| **粗編集（ラフカット）** | 飾りを付けず、**順番と長さだけ**を決める最初の作業 |
| **v0 / v1 / v2** | 作りかけの段階につける番号。`v0` は「まだ喋りだけ並べた版」 |
| **引き / 寄り** | 引き＝広く写す。寄り＝近づいて写す |
| **テロップ** | 画面に出す文字 |
| **インサート／カットイン** | 話の途中に短い別の映像をはさむこと |

## この動画だけの言葉

| 言葉 | 意味 |
|---|---|
| **レグ** | 飛行機の1区間。羽田→福岡で1レグ。**今回は全部で17レグ** |
| **Aロール** | **自分が喋っている映像。**声が主役で、話の骨組みになる |
| **Bロール** | **それ以外の映像。**空港、機窓、料理など。Aロールの上にかぶせて、画に変化をつける |
| **LSP** | Life Statusポイント。JGC入会に必要な点数 |

> **AロールとBロールの覚え方**
> Aロール＝**声を聞かせたい**映像。Bロール＝**目を楽しませる**映像。
> Aロールの声を流したまま、画面だけBロールに差し替えるのが基本の作り方。

## つなぎ方の言葉

| 言葉 | 意味 |
|---|---|
| **トランジション** | 映像から映像へ切り替わるときの効果の総称 |
| **カット（そのまま切り替え）** | 効果なしでパッと切り替える。**今回はほとんどこれ** |
| **フェード** | だんだん現れる／だんだん消える |
| **ディゾルブ（クロスフェード／ミックス）** | 前の映像と次の映像が重なりながら入れ替わる。時間が飛んだときに使う |
| **暗転** | いったん真っ黒にしてから次へ |

## 音と色の言葉

| 言葉 | 意味 |
|---|---|
| **dB（デシベル）** | 音の大きさの単位。**0が上限**で、`-6` のようにマイナスが大きいほど小さい音 |
| **LUFS** | 動画全体を通した音の大きさの基準。YouTubeは `-14` あたりが標準 |
| **グレーディング（色合わせ）** | 明るさや色みを整えて、素材ごとの差をなくす作業 |

# 全体の流れ

**1日で終わらせようとしない。3回に分けると無理がない。**

| | やること | ここで完成させるもの |
|---|---|---|
| **1回目** | 素材を振り分ける → **喋っている映像だけ**を順番に並べる | v0（喋りだけの版） |
| **2回目** | 喋りの上に**風景などの映像をかぶせる** → 音を整える | v1（見られる版） |
| **3回目** | 文字を入れる → 色を整える → 書き出す | v2（公開できる版） |

いちばん大事なのは**1回目**です。
**喋りだけを並べた状態で話が通じるなら、その動画は必ず完成します。**
逆に、そこで話が通じないのに映像や音楽で飾っても、最後まで通じません。

## 迷ったらこの順番

時間がないとき、削っていい順に並べると次のようになります。

1. 喋りを並べる ← **絶対に必要**
2. 風景の映像をかぶせる ← **必要**
3. 音の大きさを揃える ← **必要**
4. レグ番号などの文字 ← あると分かりやすい
5. BGM ← あると気持ちいい
6. 色合わせ ← 余裕があれば
7. 凝った切り替え効果 ← **今回はやらなくていい**

## この動画の冒頭をどう作るか

「導入」＝**動画のいちばん最初、視聴者が見るかどうかを決める20秒ほど**のことです。

EP002は「17レグやりきれるか？」という挑戦ものではなく、
**シドニーを出てから帰ってくるまでを順番に記録した旅の動画**にします。

なので冒頭は、**これから何を見せるのかを短く並べる**形にします（以下「旅程要約型」と呼びます）。

~~~text
シドニーから一時帰国
→ 3日間で国内線17レグ
→ 宮崎6往復
→ Day1からDay3までの移動記録
→ 初サクララウンジと初ビジネスクラス
→ シドニー帰着
~~~

参考動画のような絶景モンタージュをそのまま真似しない。今回は出発地、日付、場所、時刻、レグ番号、食事、宿泊、ラウンジ、機内、帰着を使い、4日間を順番に記録する。

本人の顔が少なくても成立させる。ただし宿で撮った振り返りを優先して使う。

旅程要約の後半でラウンジと機内素材を少し長めに使う。

~~~text
17レグの慌ただしい空港

→ 静かなラウンジ
~~~

| 旅の種類 | 適した導入 |

# 1. CapCutプロジェクトを作る

## CapCutを開く前に：素材をレグごとに振り分ける

**カメラから吸い出したままの `DJI_0123.MP4` を200本読み込むと、どれが何レグ目か分からなくなる。**
先に振り分けてから CapCut を開く。

```bash
cd scripts/organize-footage
python -m organizefootage ~/Desktop/カメラから吸い出した素材 \
  -o ~/Movies/Vlog素材/EP002-Fukuoka-JGC-Shugyo_Aug2026
```

撮影時刻から自動で判定して、こうなる。

```
01_映像/Day1/L01_HND-FUK_1250/
01_映像/Day1/L02_FUK-KMI_1525/
        …
01_映像/Day1/L05_after/          ← 屋台・ホテル・振り返り
```

- フォルダの `L03` は「3レグ目のあたりに撮ったもの」という意味。
  画面に出す `LEG 03 / 17` と同じ番号なので、編集中の数字からフォルダを探せる
- **`L03` とファイル名の `A` / `B` は別のもの。**
  `L` は撮った位置（フォルダ）、`A`/`B` はカットの種類（ファイル名）。
  ひとつの `L03` フォルダに `A003` も `B007` も入る
- `素材一覧.md` にカット番号と内容を書いてから `--apply-names` を実行すると、
  `docs/命名規則.md` のファイル名（`20260820-EP002-B002-便名表示.MP4`）に変わる
- 映像の本数が出るので、**合格ライン（150本以上）をここで確認する**
- 使い方は [`scripts/organize-footage/README.md`](../../scripts/organize-footage/README.md)

## 新規プロジェクト

1. CapCut PCを起動
2. 「プロジェクトを作成」または「新しいプロジェクト」
3. プロジェクト名を EP002_JGC-Shugyo_v01
4. 05_プロジェクトに保存できる場合は保存場所を指定
5. 比率を16:9
6. 解像度を4K
7. フレームレートを30fps

## 素材を読み込む

1. 左上「メディア」
2. 「インポート」
3. **`01_映像/Day1/L01…` から順に、レグのフォルダごと読み込む**
4. 音声（`02_音声`）、写真（`03_写真`）、BGMは別に分けて読み込む

レグのフォルダ単位で読み込めば、CapCutのメディア欄がそのまま行程順に並ぶ。
`L01 → L02 → L03 …` の順にタイムラインへ置いていけば、粗編集の骨格ができる。

読み込み後、次の順に素材を確認。

1. Aロール
2. トラブル
3. 毎レグの証拠
4. 食事
5. ラウンジ
6. ビジネスクラス
7. 環境音
8. その他

良い素材はお気に入りまたは色ラベルを付ける。機能がなければファイル名の一覧を編集メモへ記録する。

## どの段に何を置くか

タイムラインの段（トラック）ごとに、置くものを決めておきます。
**毎回同じ段に置くと、あとで探すのが楽になります。**

映像の段（下が奥、上が手前）：

| 段 | 置くもの |
|---|---|
| **V1** | 土台になる映像。喋っている映像（Aロール）はここ |
| **V2** | 喋りの上にかぶせる風景など（Bロール） |
| **V3** | ルート図、写真 |
| **V4** | 文字（テロップ、レグ番号） |

音の段：

| 段 | 置くもの |
|---|---|
| **A1** | 自分の声と、その場で一緒に録れた音 |
| **A2** | 別に録った環境音（空港のざわめきなど） |
| **A3** | BGM |
| **A4** | 効果音（クリック音、シャッター音） |

# 2. 最初にv0を作る（喋りだけの版）

**`v0` とは、喋っている映像（Aロール）だけを順番に並べただけの、いちばん最初の版のことです。**

風景も、音楽も、文字も、色の調整も入れません。**わざと入れません。**

理由は、ここで**話が通じるかどうかが分かる**からです。
喋りだけで話が通じないなら、あとから風景や音楽を足しても通じません。
逆に通じているなら、その動画はもう完成が見えています。

**ここに一番時間をかけてください。**

## Aロール（喋っている映像）を並べる

1. 喋っている映像（`A000` から `A018`）を、**撮った順に V1 の段へ置いていく**
2. 1本を選ぶ
3. **いらない部分の始まり**に再生ヘッド（縦線）を合わせる
4. ハサミのボタン、または `Ctrl+B`（Macは `Cmd+B`）で、そこを切る
5. いらないほうを選んで `Delete` キーで消す
6. 同じことを2回言っている場合は、**良いほうだけ残す**
7. クリップとクリップの間にすき間ができたら、詰める

これを17本ぶん繰り返します。**地味ですが、ここが動画の骨格です。**

残すのは、日付・場所・時刻・現在のレグ・次の予定が分かる発言。

削りやすい発言：

- 映像で分かる現在地だけ
- 前と同じ説明
- 「えー」「あのー」が長い部分
- 既にテロップで示す数字
- 丁寧すぎる前置き

言葉が不自然につながらないよう、発言の前後を0.2〜0.5秒程度残す。

## 喋りの部分は、どれくらいの長さにするか

切り終わったあと、章ごとにこれくらいに収まっていれば順調です。長すぎたらもう一度削ります。

- Day0と企画説明：1分前後
- Day1：1分〜1分20秒
- Day2：1分20秒〜1分40秒
- Day3：1分前後
- ラウンジ・ビジネス・帰着：1分〜1分20秒
- 数字と結論：40〜50秒

合計5〜6分程度。

## v0を書き出して、通して見る

**必ず一度ファイルにして、最初から最後まで見てください。** 編集画面で見るのとは印象が変わります。

1. 右上の「エクスポート（書き出し）」を押す
2. 画質は `1080p` でよい（確認用なので4Kにしなくていい）
3. `30fps`
4. ファイル名は `EP002_v0_ArollOnly.mp4`
5. 通して見て、**自分の顔と声だけで話が分かるか**を確かめる

分からない箇所があったら、**あとから声だけ録って足します**（ナレーション）。
風景の映像でごまかさないでください。内容が足りないことは、風景では埋まりません。

3. 料理の寄り
4. スプーンや箸を入れる
5. 一口目

料理全体と寄りが静止画しかない場合：

静止画は動かないので、**ゆっくり拡大させて動きをつけます**（写真がじわっと寄っていく、あの動きです）。

1. 写真をV1（いちばん下の映像の段）へ置く
2. 写真を選び、画面右側の「動画」または「基本」を開く

4. 拡大率を `100`（元のまま）にする
5. 写真の**終わり**へ再生ヘッドを動かす
6. 拡大率を `108` にする（8％だけ大きくなる）
7. 再生すると、写真がゆっくり寄っていきます

写真1枚は2〜3秒。拡大は `100 → 108` 程度。**それ以上やると不自然になります。**

1. BGMクリップを屋台直前でCtrl+B
2. 屋台部分のBGM音量を下げる
3. 調理音をA2へ置く
4. 調理音の前後に短いフェード

# 14. 色と明るさ

**目的は「きれいにする」ことではなく、「隣り合うカットの見え方を揃える」ことです。**
スマホで撮ったものとPocket 3で撮ったものが並ぶと、明るさや色みが変わって見えます。それを近づけます。

右側の「調整」を開くと、いろいろな項目が出てきます。使うのは次の4つだけです。

| 項目 | 何が変わるか | どう使うか |
|---|---|---|
| **露出／明るさ** | 画面全体の明るさ | いちばん最初に合わせる |
| **色温度** | 青っぽいか、オレンジっぽいか | 白い壁や紙が**白く見える**ように寄せる |
| **コントラスト** | 明るいところと暗いところの差 | 眠たい画のときだけ少し上げる |
| **彩度** | 色の濃さ | 触らなくてよい。派手にしすぎない |

手順：

1. タイムラインのクリップを1本選ぶ
2. 右側の「調整」を開く
3. **明るさ** → **色温度** → 必要なら**コントラスト** → **彩度** の順で触る
4. 前後のクリップと見比べて、**違和感がなくなればそれで終わり**

- 同じ場所・同じカメラで撮った素材は、1本を調整して**その数値を他へコピー**してよい
- ただし**スマホ、夜、機内、ラウンジは条件が違う**ので、まとめて同じ数値を当てない
- 「シャープ」（輪郭をくっきりさせる項目）は、**触らないのが無難**です。ざらつきが目立ちます

# 15. 音量調整

**素人の動画がいちばん見づらくなる原因が、ここです。**
映像より音のほうが、視聴者は我慢できません。

## 自分の声（Aロール）

1. 喋っているクリップを選ぶ
2. 右側の「オーディオ」を開く
3. 音量を調整する
4. 「サーッ」という雑音が気になるなら「ノイズ低減」を入れる
5. **声が細く不自然になったら、ノイズ低減を弱める。**かけすぎないこと
6. 17本の喋りを順番に聞いて、**全部同じくらいの大きさに聞こえるか**確かめる

空港と機内と屋台では、録れる音がまったく違います。**大きさを揃えるのが目的**です。

## BGM

- 喋っていないところ … BGMが**気持ちよく聞こえる**大きさ
- 喋っているところ … BGMを**大きく下げる**。「あれ、鳴ってたっけ」くらいでちょうどいい

自分では慣れてしまって気づけないので、**必ず2つの環境で確認してください。**

- イヤホン
- **スマホのスピーカー**（実際の視聴者はこれで見ます）

CapCutに「ラウドネス正規化」（全体の音量を自動で標準に合わせる機能）がある場合は使ってよいですが、
**かけたあとに必ず聞き直して**、声とBGMのバランスが崩れていないか確かめてください。
