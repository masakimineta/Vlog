# CapCut実作業手順: EP002 福岡JGC修行

> CapCut PCを開き、このファイルを上から順に実行する。
> 撮影前の想定であり、素材確認後は「編集方針の選び方」に従って変更する。
> 画面名称はCapCutの更新や地域により多少異なる。

## この動画で採用する導入

EP002は観光地の美しさが主役ではなく、**3日間で17レグを完遂できるか**が主役。

採用する導入は「疑問提示型」。

~~~text
シドニーから一時帰国
→ 3日間で国内線17レグ
→ 宮崎6往復
→ 本当に全部乗れるのか
→ 最後は初サクララウンジと初ビジネスクラス
~~~

参考動画のような絶景モンタージュをそのまま真似しない。旅の種類が違うため、今回は景色ではなく数字、時計、疲労、完遂を使う。

# 0. 素材を見て導入を決め直す

撮影後、次の順番で判定する。

## A：予定どおり完遂した

本命の「疑問提示型」を使う。

- 17レグ
- 宮崎6往復
- Day2の疲労
- 最後のラウンジとビジネスクラス

## B：遅延・欠航・屋台断念など大きなトラブルが起きた

「事件先出し型」へ変更。

最初の5秒でトラブルを見せる。

例：

~~~text
「次の便に間に合わないかもしれません」
→ 遅延表示
→ 17レグの予定図
→ タイトル
~~~

結末は冒頭で言わない。

## C：Aロールが弱い、または撮れなかった

「数字・記録型」へ変更。

- 便名表示
- 時計
- レグカウンター
- ルート図
- ナレーション

本人の顔が少なくても成立させる。ただし宿で撮った振り返りを優先して使う。

## D：景色やラウンジ、機内素材が特に良かった

「ご褒美対比型」へ変更。

~~~text
17レグの慌ただしい空港
→ 1秒無音
→ 静かなラウンジ
→ ビジネスクラス
→ 「ここに来るまで17回飛びました」
~~~

## 今後の旅行への使い分け

| 旅の種類 | 適した導入 |
|---|---|
| 修行、挑戦、制限時間あり | 疑問提示型 |
| 遅延、失敗、想定外が中心 | 事件先出し型 |
| 景勝地、リゾート | ベストショット型 |
| 食、ホテル、乗り物レビュー | 結論または一番の特徴先出し |
| 仲間との旅行 | 会話や笑い先出し |
| 静かな一人旅 | 到着前の短い独白＋風景 |

NZではベストショット型、シンガポールでは会話・出来事型が候補。毎回同じ導入テンプレートを使わない。

# 1. CapCutプロジェクトを作る

## 新規プロジェクト

1. CapCut PCを起動
2. 「プロジェクトを作成」または「新しいプロジェクト」
3. プロジェクト名を EP002_JGC-Shugyo_v01
4. 05_プロジェクトに保存できる場合は保存場所を指定
5. 比率を16:9
6. 解像度を4K
7. フレームレートを30fps

## 素材を読み込む

1. 左上「メディア」
2. 「インポート」
3. 日付フォルダごとに読み込む
4. 動画、音声、写真、BGMを分ける

読み込み後、次の順に素材を確認。

1. Aロール
2. トラブル
3. 毎レグの証拠
4. 食事
5. ラウンジ
6. ビジネスクラス
7. 環境音
8. その他

良い素材はお気に入りまたは色ラベルを付ける。機能がなければファイル名の一覧を編集メモへ記録する。

## タイムラインの役割

- V1：Aロールと本編の基礎映像
- V2：Aロールを隠すBロール
- V3：ルート図、写真、補足画面
- V4：テロップ、レグカウンター
- A1：Aロールの声、現場音
- A2：環境音
- A3：BGM
- A4：効果音

# 2. 最初にv0を作る

v0ではBGM、色、派手なテロップを入れない。

## Aロールを並べる

1. A000からA018までをV1へ時系列で置く
2. 各クリップを選択
3. 再生ヘッドを不要部分の開始へ移動
4. ハサミまたは Ctrl+B で分割
5. 不要部分を選んでDelete
6. 言い直しは良いほうだけ残す
7. クリップ間の空白を詰める

残すのは、状況や感情が変化した発言。

削りやすい発言：

- 映像で分かる現在地だけ
- 前と同じ説明
- 「えー」「あのー」が長い部分
- 既にテロップで示す数字
- 丁寧すぎる前置き

呼吸を全部消さない。疲労や安堵を見せるコメントでは前後0.3〜0.7秒残す。

## Aロールの目標尺

- Day0と企画説明：1分前後
- Day1：1分〜1分20秒
- Day2：1分20秒〜1分40秒
- Day3：1分前後
- ラウンジ・ビジネス・帰着：1分〜1分20秒
- 数字と結論：40〜50秒

合計5〜6分程度。

## v0を書き出す

1. 右上「エクスポート」
2. 1080p
3. 30fps
4. ファイル名 EP002_v0_ArollOnly.mp4
5. 通して見て、顔だけでも話が分かるか確認

分からない箇所は、帰宅後ナレーションを追加する。Bロールで内容不足をごまかさない。

## CapCutでの具体的な配置

### 0:00〜0:03

1. 便名表示または飛行機をV1へ置く
2. 右端をドラッグして3秒へ短縮
3. A2へ空港チャイムまたは環境音
4. 最初の0.2秒は黒から始める
5. 必要なら「トランジション」→「フェード」または「暗転」を0.2秒

テロップなしでもよい。最初に場所の音を聞かせる。

### 0:03〜0:06

1. シドニーでキャリーを引く素材をV1
2. 3秒へ短縮
3. 「テキスト」→「デフォルトテキスト」
4. 一時帰国の4日間で と入力
5. 画面下中央へ配置
6. 白文字＋黒の影
7. 入場アニメーションはフェード、0.2秒程度

### 0:06〜0:10

1. 便名表示を3〜4本選ぶ
2. 各0.7〜1秒へ短縮
3. 隙間なく並べる
4. V4に 03/17 → 08/17 → 14/17 → 17/17 の数字
5. A4に同じ小さなクリック音
6. 数字が変わる位置とクリック音の波形を合わせる

強いトランジションは入れない。瞬時に切り替える。

### 0:10〜0:13

1. 宮崎6回目の時計を3秒
2. 画面中央に 宮崎6回目／滞在30分
3. 文字は2行以内
4. 重要な時刻が文字で隠れない位置に置く

### 0:13〜0:16

1. Day2で最も疲れが分かるAロール
2. 3秒程度へ切る
3. 本編から一文を先出し
4. BGMを少し下げ、声を明瞭にする

候補：

~~~text
「景色が全部同じに見えてきました」
「今、何本目か分からなくなってきました」
~~~

実際に言っていない言葉を作らない。

### 0:16〜0:19

1. サクララウンジ入口
2. 3秒
3. 前のBGMを0.2〜0.4秒で下げる
4. ラウンジ用の静かな曲を開始
5. 初めてのサクララウンジ と表示

### 0:19〜0:22

1. ビジネスクラス座席
2. 3秒
3. 17レグの先に。 と短く表示
4. 最後の0.2秒でタイトル映像へ切り替える

## タイトル 0:22〜0:32

1. 機窓またはシドニー空港の広い固定映像を10秒
2. V4へタイトル
3. 一時帰国でJGC修行
4. その下に 3日間・国内線17レグ
5. フォントは本編と同じ
6. 入場はフェード0.3秒
7. 2秒静止
8. 退場はフェード0.3秒

タイトルへズーム・回転・虹色効果は使わない。

# 4. Day0を作る

## 並べる順番

B000a空港名 → キャリー → 出発案内 → A000 → 搭乗口 → 機窓 → 機内食 → 日本到着 → 到着コメント

## A000へBロールを載せる

1. A000をV1へ置く
2. A000の声はそのまま使う
3. B000aなどをV2へ重ねる
4. 話している内容と画を合わせる

例：

- 「シドニーから」→ 空港名
- 「一時帰国」→ キャリー
- 「17レグ」→ ルート図
- 「福岡と宮崎を6往復」→ FUK↔KMI表示

同じBロールを5秒以上載せない。A000の顔も途中で一度戻す。

## シドニー→日本の場面転換

1. 機窓素材と日本到着素材を隙間なく並べる
2. 時間経過を柔らかく見せたい場合だけ、境目をクリック
3. 「トランジション」からミックス、クロスフェード、ディゾルブに近いもの
4. 長さ0.3秒
5. 二重映像が目立つなら削除して通常の切り替えへ戻す

# 6. 毎レグの共通編集

## レグ開始カード

1. 新しいレグの最初へ再生ヘッド
2. V4へテキスト
3. 次の形式で入力

~~~text
LEG 03 / 17
FUK → KMI　15:25
~~~

4. 3秒の長さ
5. 左下または中央
6. 入場フェード0.15〜0.25秒
7. 退場フェード0.15〜0.25秒

3秒後は小さい 03 / 17 だけ右上へ残してもよい。全編常時表示すると映像を邪魔する場合は、レグ開始時だけでよい。

## 共通の並び

便名表示 → 搭乗口 → 足元または機体 → シートベルト → 機窓 → 到着表示 → Aロール

目安：

- 便名表示：1〜1.5秒
- 搭乗口：1〜1.5秒
- 搭乗：1.5〜2秒
- 機内：1〜2秒
- 機窓：2〜3秒
- 到着：1〜2秒
- Aロール：必要な一文

17回すべてを同じ長さで見せない。初回と最終回は長く、中間は短くする。

# 7. Day1を作る

## 見せ方

Day1は新鮮さを残すため、Day2より少し長いカットを使う。

宮崎1回目だけ：

- 宮崎表示
- 時計
- ヤシの木
- 売店
- 展望デッキ
- A003

宮崎2回目は、夜の変化と「同じ路線2回目」だけ。

## 食事

1. 店名
2. 料理全体
3. 料理の寄り
4. スプーンや箸を入れる
5. 一口目
6. 感想

料理全体と寄りが静止画しかない場合：

1. 写真をV1へ置く
2. 右側「動画」または「基本」
3. 開始位置でスケール横のひし形
4. スケール100
5. 終了位置へ移動
6. スケール108
7. 必要なら位置も少し調整

写真1枚は2〜3秒。ズームは100→108程度。

## 屋台

最初の1〜2秒はBGMを止め、調理音を聞かせる。

CapCut：

1. BGMクリップを屋台直前でCtrl+B
2. 屋台部分のBGM音量を下げる
3. 調理音をA2へ置く
4. 調理音の前後に短いフェード
5. A005が始まったらBGMを小さく戻す

行けなかった場合は、時計→遅延表示→本人コメント。無理に別の観光素材を入れない。

# 8. Day2を作る

## 3往復の違い

- 3往復目：朝、元気。35〜45秒
- 4往復目：慣れ。25〜35秒
- 5往復目：疲労。45〜60秒

## 反復モンタージュ

各往復から同じ種類の素材を選ぶ。

1. 便名表示
2. 搭乗口
3. シートベルト
4. 機窓
5. 宮崎表示
6. 時計

最初の往復は各1秒、2回目は0.8秒、3回目は0.6〜0.8秒。

BGMの波形に目立つ山があれば、その位置へ映像の境目を合わせる。ただし全部のビートに合わせない。

## 3分割

同じ機窓が3本揃った場合のみ。

1. 3素材をV1、V2、V3へ同じ開始位置で重ねる
2. 1本目を選択
3. 右側「動画」→「基本」→「スケール」と「位置」
4. 横幅約1/3になるよう縮小
5. 左へ移動
6. 2本目を中央
7. 3本目を右
8. 必要なら「マスク」→長方形で余分を切る
9. 3〜4秒にそろえる
10. 下へ時刻を表示

画面が分かりにくければ、3分割をやめて順番に切り替える。

## 疲労コメント

疲れたAロールの直前でBGMを分割し、音量を下げる。

1. BGMを選択
2. コメント開始0.3秒前でCtrl+B
3. コメント終了0.3秒後でCtrl+B
4. 中央部分の音量を下げる
5. 前後にフェードまたは音量キーフレーム

音量キーフレームを使う場合：

1. BGMを選択
2. コメント前で音量のひし形
3. 0.3秒後でもう1点を作り音量を下げる
4. コメント後に逆の2点を作る

# 10. サクララウンジを作る

## 順番

入口 → 全景 → 窓 → 食事 → 飲み物 → A017 → 食後感想

## 音で場面を変える

1. 羽田到着のBGMをラウンジ入口まで伸ばす
2. 入口でBGMを分割
3. 前曲を0.5秒でフェードアウト
4. 0.3〜0.8秒だけ環境音
5. 静かなラウンジ用BGMをフェードイン

強い映像トランジションは不要。

## A017

A017の声をV1/A1へ置き、ラウンジBロールをV2へ重ねる。

発言と対応：

- 「初めて」→入口
- 「静か」→空席または窓
- 「助かった」→座席、飲み物、食事
- 「また利用したい」→本人の顔へ戻る

全体で1分10秒程度。設備を網羅しない。

# 11. ビジネスクラスを作る

## 順番

搭乗口 → 搭乗 → 座席全体 → 収納 → 画面 → 飲み物 → 離陸 → 機内食 → フルフラット → 消灯 → 朝 → 到着

## 設備カット

各1.5〜2.5秒。説明したいものだけ残す。

## 座席の前後比較

同じ画角が撮れていれば：

1. 通常状態を2秒
2. 瞬時にフルフラット状態へ切り替える
3. AFTER または FULL FLAT と短く表示

画角が違えば無理に比較しない。

## 機内食

全体2秒 → 前菜1.5秒 → メイン2秒 → デザート1.5秒 → 感想。

料理写真しかなければ100→108の緩いズーム。

## 消灯→朝

1. 夜の機内または暗い機窓
2. BGMを1秒程度でフェードアウト
3. 巡航音を残す
4. 朝の機窓へ0.3秒ディゾルブ
5. 新しい静かなBGMを開始

# 12. シドニー帰着とエンディング

## 出発と帰着を対応させる

動く方向が同じなら、隙間なく置いて通常の切り替え。違う方向なら無理に合わせず、空港表示を挟む。

## 最後

1. A018の総括
2. シドニーの朝または空港外
3. ルート図完成形
4. 4 DAYS / 17 DOMESTIC FLIGHTS / 85 LSP EXPECTED
5. Thank you for watching
6. 黒画面または終了画面用の静止映像を8〜10秒

終了画面用に画面右側または左右へ余白を残す。

# 13. 字幕を作る

## 自動字幕

1. 左側「キャプション」または「テキスト」
2. 「自動キャプション」
3. 音声ソースを選択
4. 日本語
5. 「生成」または「認識」
6. 各字幕を確認して修正

自動字幕はそのまま使わない。JGC、LSP、空港名、便名は誤認識しやすい。

## 字幕を減らす

全発言を常時字幕にしない場合：

- 数字
- 結論
- 聞き取りにくい箇所
- 感情の強い一文

だけ残す。

字幕は2行以内。画面下端へ寄せすぎない。

# 14. 色と明るさ

1. タイムラインのクリップを1本選択
2. 右側「調整」
3. まず露出または明るさ
4. 次に色温度
5. 必要ならコントラストと彩度
6. 前後のクリップと見比べる

調整の順番は、明るさ→白の色→コントラスト→彩度。

Pocket 3の設定が同じ素材は、1本を調整して値を記録し、近い条件の素材へコピーしてもよい。スマホ、夜、機内、ラウンジには同じ値を一括適用しない。

シャープは少量。輪郭やノイズが目立ったら戻す。

---

# 15. 音量調整

## Aロール

1. Aロールを選択
2. 右側「オーディオ」
3. 音量を調整
