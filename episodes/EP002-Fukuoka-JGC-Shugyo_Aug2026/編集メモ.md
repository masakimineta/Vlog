## 撮影前に決めておく編集方針

同じ路線の往復が続くので、**素材の差ではなく編集の仕掛けで飽きさせない**構成にします。

- **レグカウンター**: 画面隅に `⑦/17` のような通し番号を常時表示し、レグが変わるたびに加算する
- **同一画角の三分割**: Day2 の 3 往復ぶんの機窓（B021）を並べ、雲しか変わらないことを見せる
- **ルート図（B033）**: 3 日間の線が増えていくアニメーション。導入・Day3 冒頭・まとめの 3 回使う。
  `scripts/route-map` で生成する（下記）
- **宮崎の滞在時間**: 到着時刻と出発時刻のテロップをセットで出し、6 回ぶんを積み上げる
- **搭乗券の束（B018）**: 日をまたぐたびにインサートして、枚数の増加で時間経過を示す

### ルート図（B033）の作り方

```bash
cd scripts/route-map
pip install -r requirements.txt
python -m routemap --size 4k -o ~/Desktop/EP002-routemap.mp4      # 全17レグ・通し
python -m routemap --days 3 --size 4k -o ~/Desktop/EP002-day3.mp4 # Day3 冒頭用
python -m routemap --alpha -o ~/Desktop/EP002-routemap.mov        # 映像に重ねる場合
```

**遅延・欠航で行程が変わったら `scripts/route-map/routemap/itinerary.py` の
`LEGS` を直して実行し直す。** 手で描き直す必要はない。

福岡⇔宮崎の 6 往復は、往路と復路が反対側に膨らんで扇状に開くようになっている
（同じ線が重なって画面が止まって見えるのを避けるため）。開き具合は
`--bow-spread` で調整する。

## この編集で練習すること

EP002は公開作品であると同時に、10月のNZ、11月のシンガポールに向けた編集リハーサル。

優先順位は次のとおり。

1. Aロールだけで物語の骨格を作る
2. Aロールの言葉をBロールで自然に隠す
3. 環境音から場所を感じさせる
4. 1日の中の感情変化を編集でつなぐ
5. 撮影後2週間以内に完成させる

今回の合格条件は、凝った画面効果ではなく、次のワークフローを最後まで経験すること。

- 素材整理
- Aロールの粗編集
- Bロールの差し込み
- 音声とBGMの調整
- テロップ
- 色合わせ
- 書き出しと修正
- 次回への申し送り

NZで練習する風景の画作りやグレーディング、シンガポールで必要になる会話・食事・ホテルの総合演出は、EP002では追求しすぎない。

## 最初に作るAロール版

素材整理後、BGM・テロップ・色調整を始める前に、Aロールだけを次の順番で並べる。

1. シドニー出発
2. 羽田で企画説明
3. 各レグの短い現在地と気分
4. Day1終了コメント
5. Day2朝・中盤・終了コメント
6. Day3朝・最終宮崎・17レグ完了
7. 初サクララウンジ
8. ビジネスクラス搭乗前後
9. シドニー到着
10. 帰宅後の費用・LSP説明

Aロールだけで14分を超えた場合、同じ内容を説明している発言から削る。

残す発言の優先順位：

1. 状況が変わった
2. 感情が変わった
3. 想定外が起きた
4. 数字を説明する
5. 既に画面で分かることを説明する

「今、宮崎空港にいます」のように画面だけで分かる発言は短縮し、「5回目で空港の配置を覚えた」のような本人にしか言えない感想を残す。

Aロールの完成尺は全体の35〜45％、約5〜6分を目安にする。

## 章ごとの編集指示

### Day0 シドニー→日本

順番：

1. 空港名
2. キャリーケース
3. 出発案内
4. A000
5. 搭乗口
6. 機窓
7. 機内食
8. 日本到着
9. 到着コメント

全体で45秒前後。国際線レビューではなく、修行へ向かう導入として扱う。

シドニー離陸から日本到着は、機窓を使って直接切り替えるか、0.3秒程度の短いディゾルブにする。

### 企画説明

A001の顔を長く見せ続けない。話し始めから10秒以内にルート図へ切り替える。

表示する数字：

- JGC入会基準：1,500 LSP
- 国内線：1搭乗5 LSP
- 今回：17搭乗、85 LSP見込み

一画面に出す数字は最大3項目。注記は2〜3秒だけ表示。

### Day1

テーマは「まだ旅行として新鮮」。

- 空港全景：3〜4秒
- 食事：各2〜3秒
- 機窓：3〜4秒
- Aロール：一文ごとに不要な間を切る

宮崎空港の説明は1回目だけ詳しく行い、2回目以降は変化だけを見せる。

屋台へ行けた場合は、最初の1〜2秒だけBGMを止め、調理音や街の音を聞かせる。

屋台へ行けなかった場合は、時計、暗い空港、本人のコメントで「修行へ観光を組み込む難しさ」を見せる。失敗を隠さない。

### Day2

テーマは「反復で感覚が変わる」。

| 往復 | 目安尺 | 内容 |
|---|---:|---|
| 3往復目 | 35〜45秒 | 朝、まだ元気 |
| 4往復目 | 25〜35秒 | 空港に慣れた |
| 5往復目 | 45〜60秒 | 疲労と本音。山場 |

反復部分は、同じ順番の短い素材で見せる。

~~~text
便名表示 0.7秒
→ 搭乗口 0.7秒
→ シートベルト 0.7秒
→ 機窓 1秒
→ 宮崎表示 0.7秒
→ 時計 0.7秒
~~~

3回目の反復では途中でBGMを止め、疲れたコメントへ切り替える。

同一画角の機窓が3本揃った場合だけ3分割を使う。3〜4秒で十分。素材が揃わなければ無理に作らない。

疲労は派手な画面効果ではなく、時計、座った足元、歩く速度、バッテリー残量、短くなる発言で見せる。

### Day3・17レグ完了

章の冒頭で「残り5レグ」を大きく表示し、以後カウントダウンする。

最後の宮崎：

~~~text
ARRIVAL 12:35
DEPARTURE 13:05
TURNAROUND 30 MIN
~~~

羽田到着までは「完了」と表示しない。福岡出発時は FINAL LEG。

羽田到着時：

1. 着陸または到着表示
2. 0.5〜1秒だけ音を抑える
3. 17 / 17 COMPLETE
4. 本人の安堵コメント
5. 明るいBGMへ変更

### 初サクララウンジ

テーマは「騒がしい反復から静けさへ」。

順番：

1. 入口
2. 空席中心の全景
3. 窓
4. 食事を取る手元
5. 料理
6. 飲み物
7. 初利用のコメント
8. 食後の短い感想

施設紹介を網羅しない。次の3点だけ答える。

- 入った瞬間の印象
- 17レグ後に一番助かったもの
- また利用したいか

ラウンジの会話音は使わず、食器や飲み物の手元音だけ短く使う。

### JL51ビジネスクラス

商品レビューではなく「ようやく休める帰路」。

順番：

1. JL51搭乗口
2. 搭乗
3. 座席全体
4. 収納・画面・操作部
5. 飲み物
6. 離陸・機窓
7. 機内食
8. 座席を倒す前後
9. 消灯
10. 朝の光
11. 到着後コメント

設備は各1.5〜2.5秒。全部の機能を説明しない。

消灯時にBGMを消し、巡航音を残す。朝の機窓で静かな別の曲を始める。

### シドニー帰着

Day0と似た構図を使う。

例：出発時にキャリーを引く足元 → 帰着時にキャリーを引く足元。

同じ方向へ動く映像同士なら、瞬時に切り替えても自然につながる。

最後のコメント後：

1. シドニー空港外または朝の景色
2. ルート図完成形
3. 4 DAYS / 17 DOMESTIC FLIGHTS / 85 LSP EXPECTED
4. 黒画面
5. Thank you for watching

## 切り替え方法

### 普通の切り替え

ほとんどの場所ではエフェクトを入れず、瞬時に次の映像へ変える。

使用箇所：

- 同じ空港内
- 食事の別角度
- 機内設備
- 同じ日の移動
- Aロールから補足映像

### ディゾルブ

前後の映像が短く重なる切り替え。長さは0.2〜0.4秒。

使用候補：

- 夜から朝
- シドニーから日本
- 機内消灯から朝
- 時間が大きく経過した場面

全編で5回以内。

### 強いトランジション

ズーム、歪み、虹色、回転は基本的に使わない。使う場合はDay2の反復で1種類だけ、最大2回。

## テロップのルール

- 読みやすいゴシック体1種類
- 基本は白文字
- 黒い影または半透明背景
- 強調色は赤1色
- 一画面2行まで
- 一行20文字程度まで
- 上下左右の端へ寄せすぎない

### 場所表示

左下：

~~~text
FUKUOKA AIRPORT
DAY 1 / 14:35
~~~

### レグ表示

レグ開始時に3秒表示：

~~~text
LEG 03 / 17
FUK → KMI
15:25
~~~

その後は 03 / 17 だけ右上に残す。

### 発言テロップ

全文を書き起こさず、重要な意味だけ表示する。

発言：「3往復目になると、雲の位置しか変わりません」

表示：「変わるのは、雲の位置だけ。」

搭乗券、スマホ画面、予約番号、会員番号などは必ずぼかす。

## 音のルール

優先順位：

1. 本人の声
2. 環境音
3. BGM
4. 効果音

目安：

- 話し声のピーク：おおむね -6〜-3 dB
- 会話中のBGM：話し声より15〜20 dB程度小さく
- 最終書き出し：YouTube向け -14〜-16 LUFS程度を目安

環境音を使う場所：

- シドニー空港
- 搭乗アナウンス
- 屋台
- 鉄板焼
- ラウンジの食器や飲み物
- 機内巡航音
- シドニー到着

各場所の最初の1秒だけBGMを下げると、場所の変化が伝わりやすい。

効果音は、レグ加算のクリック、ルート線追加、数字表示、写真のシャッター音に限定する。同じ動作には同じ音を使う。

## スマホとPocket 3の色合わせ

完全一致を目標にしない。

1. 明るさを合わせる
2. 白い部分の黄・青の偏りを抑える
3. コントラストを軽く合わせる
4. 必要な場合だけ彩度を調整

強いフィルターを全素材へ一括適用しない。空港、夜の機内、ラウンジは個別に調整する。

手ブレ補正は必要な素材だけ。画面端が歪む場合は補正を弱めるか、カットを短くする。
