# episodes

エピソードごとの作業フォルダを置く場所です。

## 一覧

| ID | タイトル | 公開日 | ステータス |
|----|---------|--------|-----------|
| EP000 | サンプル（朝の準備ルーティン） | — | 見本 |
| EP001 | New Zealand Vlog_Jan 2026 | 2026-09-06（予定） | 編集中 |

新しいエピソードを作ったら、この表に 1 行追加してください。

## フォルダの作り方

```bash
./scripts/new-episode.sh 001 京都の朝さんぽ
```

`episodes/EP001-京都の朝さんぽ/` が作られ、`templates/` の雛形がコピーされます。

## ステータスの意味

| ステータス | 状態 |
|-----------|------|
| 企画中 | 企画書を書いている |
| 撮影待ち | 台本・撮影計画ができ、撮影日待ち |
| 編集中 | 撮影完了、編集作業中 |
| 公開済み | 公開して URL を記録済み |
| 保留 | 一度止めた企画 |
