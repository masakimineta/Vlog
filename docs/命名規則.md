# 命名規則

素材が増えても迷子にならないように、フォルダ名・ファイル名のルールを決めておきます。

## 基本方針

- 日付は `YYYYMMDD` 形式（並び替えたときに時系列になる）
- 単語の区切りはハイフン `-`、スペースは使わない
- 連番は必ずゼロ埋め（`001` であって `1` ではない）
- 記号は `-` と `_` のみ。`/ \ : * ? " < > |` は使わない

## エピソードフォルダ（このリポジトリ内）

```
episodes/EP001-京都の朝さんぽ/
├── 企画書.md
├── 台本.md
├── 撮影計画.md
├── 編集メモ.md
└── 公開情報.md
```

形式: `EP<3桁の連番>-<短いタイトル>`

タイトルは公開タイトルそのままでなく、識別できる程度の短いもので構いません。

## 素材フォルダ（外部ストレージ）

```
Vlog素材/
└── EP001-京都の朝さんぽ/
    ├── 01_映像/
    │   ├── 20260412-EP001-A001-清水寺.mp4
    │   └── 20260412-EP001-B012-手元.mp4
    ├── 02_音声/
    │   └── 20260412-EP001-環境音-鴨川.wav
    ├── 03_写真/
    ├── 04_BGM効果音/
    ├── 05_プロジェクト/     # 編集ソフトのプロジェクトファイル
    └── 06_書き出し/
        └── 20260420-EP001-v3-final.mp4
```

### 映像ファイル

```
<撮影日>-<エピソードID>-<カット番号>-<内容>.<拡張子>
20260412-EP001-A001-清水寺.mp4
```

- カット番号の接頭辞: `A` = メインカット（喋り・被写体）、`B` = B ロール
- カット番号は `撮影計画.md` のカットリストの番号と一致させる

### 素材が多い旅では、撮った順のサブフォルダを作ってよい

移動が多く素材が 100 本を超える旅では、`01_映像/` の直下がファイルで埋まって探せなくなります。
その場合だけ、**撮った順が分かるサブフォルダ**を挟んで構いません。

```
01_映像/
├── Day1/
│   ├── L01_HND-FUK_1250/
│   │   ├── 20260820-EP002-A001-羽田で導入.mp4
│   │   └── 20260820-EP002-B002-便名表示.mp4
│   └── L03_KMI-FUK_1745/
└── Day2/
```

**フォルダ名とファイル名は別の軸です。混同しないでください。**

| | 意味 | 例 |
|---|---|---|
| フォルダの `L03` | **いつ撮ったか**（3 レグ目のあたり） | `L03_KMI-FUK_1745/` |
| ファイルの `A` / `B` | **どんなカットか**（喋りか、それ以外か） | `…-B012-便名表示.mp4` |

ひとつの `L03` フォルダの中に、`A003` も `B007` も入ります。
区間の呼び方（`L`）は旅によって変わって構いませんが、**ファイル名の `A` / `B` は変えません**。

このサブフォルダは `scripts/organize-footage` が撮影時刻から自動で作ります。

### 音声ファイル

```
<撮影日>-<エピソードID>-<種別>-<内容>.wav
20260412-EP001-環境音-鴨川.wav
20260412-EP001-ナレーション-導入.wav
```

種別は `環境音` / `ナレーション` / `ピンマイク` などを使います。

### 書き出しファイル

```
<書き出し日>-<エピソードID>-v<版数>[-final].mp4
20260420-EP001-v3-final.mp4
```

最終版にのみ `-final` を付けます。`最終` `最終2` `本当の最終` のような命名は禁止です。

## サムネイル

```
<エピソードID>-サムネ-v<版数>.png
EP001-サムネ-v2.png
```
