# 公開チェックリスト

公開ボタンを押す前に、上から順に確認します。
エピソードごとにこのファイルをコピーして使っても構いません。

## 映像

- [ ] 冒頭 15 秒で内容が伝わるか
- [ ] 不要な間・言い淀みがカットされているか
- [ ] カットのつなぎ目に違和感がないか
- [ ] カラーがカット間で揃っているか
- [ ] ピントの外れたカットが残っていないか
- [ ] 書き出し設定（解像度・ビットレート・フレームレート）が正しいか
- [ ] 最後まで通しで 1 回見たか

## 音声

- [ ] 全体の音量が揃っているか（-14 LUFS 目安）
- [ ] BGM が声を邪魔していないか
- [ ] ノイズ（風切り音・空調音）が処理されているか
- [ ] 突然の大音量がないか
- [ ] イヤホンとスピーカーの両方で確認したか

## テロップ・字幕

- [ ] 誤字脱字がないか
- [ ] 表示時間が読み切れる長さか
- [ ] 画面端で見切れていないか（セーフエリア内か）
- [ ] スマホの画面サイズで読めるか

## 権利・プライバシー

- [ ] BGM・効果音のライセンスを確認し、必要なクレジットを概要欄に記載したか
- [ ] 使用した写真・映像素材の利用条件を満たしているか
- [ ] 映り込んだ第三者の顔・車のナンバー・表札などを処理したか
- [ ] 位置情報が特定されすぎていないか（自宅周辺など）
- [ ] 店舗・施設の撮影許可が必要な場所ではないか

## 公開情報

- [ ] タイトルが決まっているか（35 文字以内目安）
- [ ] 概要欄を書いたか（冒頭 2 行で内容が伝わるか）
- [ ] タグ・ハッシュタグを設定したか
- [ ] チャプター（タイムスタンプ）を入れたか
- [ ] サムネイルを設定したか（スマホサイズで文字が読めるか）
- [ ] 再生リストに追加したか
- [ ] 終了画面・カードを設定したか
- [ ] 公開範囲・公開日時を確認したか

## 公開後

- [ ] 実際に再生して映像・音声が正常か確認したか
- [ ] `公開情報.md` に公開 URL と公開日を追記したか
- [ ] `編集メモ.md` の「次回への申し送り」を書いたか
