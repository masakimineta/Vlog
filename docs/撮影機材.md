## 撮影設定のプリセット

### 屋外・日中

- 解像度 / フレームレート: 4K 30p（スローを使うカットは 4K 60p）
- シャッタースピード: フレームレートの 2 倍（30p なら 1/60）
- ISO: ベース ISO 固定
- ND フィルター: 明るさに応じて（晴天なら ND8〜ND16）
- ホワイトバランス: マニュアル（5600K 目安）
- ピクチャープロファイル: （記入する）

### 屋内・室内撮影

- 解像度 / フレームレート: 4K 30p
- ホワイトバランス: マニュアル（電球色なら 3200K 目安）
- 照明: メインライトは被写体の斜め 45 度から

### 手持ち移動

- 手ブレ補正 ON
- シャッタースピードは上げすぎない（カクつきの原因になる）

## 持ち物チェック（撮影前日）

- [ ] カメラバッテリー（予備含めて 3 本以上）
- [ ] SD カード（フォーマット済み・空き容量確認）
- [ ] マイクの電池
- [ ] レンズクリーナー
- [ ] モバイルバッテリー
- [ ] 三脚 / ジンバル（充電済み）
- [ ] ND フィルター
- [ ] 雨具（屋外撮影の場合）

## 気をつけていること

- 撮影開始前に必ずテスト録画をして音声が乗っているか確認する
- SD カードは撮影ごとにフォーマットせず、バックアップ後にフォーマットする
- ジンバルのキャリブレーションは現地で毎回やり直す
