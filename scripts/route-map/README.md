# routemap — 行程からルート図のアニメーションを作る

地図の上を線が 1 本ずつ伸びていく、あの動画を作ります。
台本の `[映像] B033 ルート図` に使うものです。

```bash
cd scripts/route-map
python -m routemap -o ~/Desktop/EP002-routemap.mp4
```

これで **17 レグぶんの線が順番に伸びる約 12 秒の動画**が出てきます。

## セットアップ

```bash
pip install -r requirements.txt
```

ffmpeg が入っていれば `imageio-ffmpeg` は不要です。入れていなければ、
requirements.txt に入っている `imageio-ffmpeg` が同梱の ffmpeg を使います。

## 行程を変える

**`routemap/itinerary.py` だけ編集します。** ほかのファイルは触りません。

```python
LEGS = [
    Leg(1, "HND", "FUK", "12:50"),   # 1 日目、羽田 → 福岡、12:50 発
    Leg(1, "FUK", "KMI", "15:25"),
    ...
]
```

- 便を減らすなら行を消す、増やすなら行を足す
- 順番を入れ替えれば、描かれる順番も変わる
- 空港を増やすときは `AIRPORTS` に 1 行足す（緯度・経度は Google マップで
  空港を右クリックすると出ます）

遅延や欠航で行程が変わったら、ここを直して実行し直すだけです。

## 福岡⇔宮崎が 6 往復でも潰れない理由

同じ区間を繰り返すと線がぴったり重なって、画面が止まって見えます。
そこで **往路と復路を反対側に曲げ、往復するごとに外へ広げて扇状にして**います。
6 往復すると上下に 6 本ずつ開いた形になり、「何回飛んだか」が一目で分かります。

広がり方を変えたいとき:

```bash
python -m routemap --bow-spread 0.026   # もっと大きく開く
python -m routemap --bow-spread 0        # 開かず全部重ねる
```

## よく使う指定

| やりたいこと | コマンド |
|---|---|
| 本番用に 4K で出す | `python -m routemap --size 4k -o out.mp4` |
| 映像に重ねる（背景を透過） | `python -m routemap --alpha -o out.mov` |
| 明るい配色にする | `python -m routemap --theme light` |
| 海岸線なしのシンプルな図 | `python -m routemap --no-map` |
| Day1 だけ描く | `python -m routemap --days 1` |
| ゆっくり描く | `python -m routemap --draw-sec 0.7` |
| 連番 PNG で出す | `python -m routemap --frames ./seq` |

指定できるものは `python -m routemap --help` で全部出ます。

## 出力形式

| 拡張子 | 中身 | 透過 |
|---|---|---|
| `.mp4` | H.264 | × |
| `.mov` | ProRes 4444 | ○ |
| `.webm` | VP9 | ○ |

**透過が必要なら `.mov` か `.webm` にしてください。** MP4 は透過を保存できないので、
`--alpha` と `.mp4` を同時に指定するとエラーになります。

ProRes はきれいなぶんファイルが大きくなります（10 秒で 100 MB を超えます）。
編集ソフトに読ませたら消して構いません。

## 台本での使いどころ

台本では B033 を 3 回使う想定です。

| 場所 | 使い方 |
|---|---|
| 導入（0:00-0:50） | 全 17 レグが一気に増えるダイジェスト |
| Day3 冒頭（8:20） | `--days 3` でその日のルートだけ |
| まとめ（11:30） | 描き終わった状態を静止画的に見せる |

通しで 1 本作って必要なところを切り出すか、`--days` で日ごとに作り分けるかは
編集しやすいほうで構いません。

## 実行にかかる時間

1080p で 1 分ほど、4K だと 10 分前後かかります（`--supersample 2` の場合）。
確認しながら調整するときは `--size 720p` で回して、決まってから 4K で出すのが楽です。

## 地図データについて

`routemap/data/japan-coastline.json` は Natural Earth（1:50m, パブリックドメイン）の
海岸線を、九州〜関東の範囲に切って間引いたものです。13 KB しかないので、
外部の地図サービスに接続しなくてもオフラインで動きます。

範囲を変えたいときは `render.py` の `Renderer.__init__` にある余白の数値
（`- 1.6` `+ 1.4` など）を調整してください。
