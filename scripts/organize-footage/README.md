# organize-footage — 素材を行程どおりに振り分ける

カメラから吸い出した素材を、**撮影時刻から「何レグ目のものか」を判定して**
フォルダへ振り分け、素材一覧を作ります。

3日で約200本撮ったあと、CapCutで「これはどのレグの映像か」を1本ずつ思い出す作業がなくなります。

```bash
cd scripts/organize-footage
python -m organizefootage ~/Desktop/カメラから吸い出した素材 \
  -o ~/Movies/Vlog素材/EP002-Fukuoka-JGC-Shugyo_Aug2026
```

## 何をしてくれるか

```
01_映像/
├── Day0_Sydney出発/
├── Day1/
│   ├── L01_HND-FUK_1250/     ← 12:50発の便に乗る前後に撮ったもの
│   ├── L02_FUK-KMI_1525/
│   ├── L03_KMI-FUK_1745/
│   ├── L04_FUK-KMI_1915/     ← カフェの素材はここに入る（次に乗る便で分類）
│   ├── L05_KMI-FUK_2130/
│   └── L05_after/            ← 屋台・ホテル・振り返り
├── Day2/ …
├── Day3/ …
└── Day4_JL51機内-Sydney到着/
02_音声/  03_写真/  00_未分類/
素材一覧.md
```

フォルダ名の `L03` は、テロップの `LEG 03 / 17` と同じ番号です。
**CapCutでは L01 から順にフォルダごと読み込めば、それだけで時系列に並びます。**

`素材一覧.md` には全ファイルの時刻・振り分け先・カット番号の記入欄が出ます。
`撮影計画.md` のカットリストと突き合わせるときに使ってください。

## 行程を変えたとき

**`scripts/route-map/routemap/itinerary.py` の `LEGS` を直すだけです。**
このツールはそこから行程を読むので、ルート図の動画と素材の振り分けが必ず一致します。

日付だけは `organizefootage/schedule.py` の `DAY_DATES` にあります。

## よく使う指定

| やりたいこと | コマンド |
|---|---|
| 実際には動かさず結果だけ見る | `--dry-run` |
| コピーではなく移動する | `--move` |
| カメラの時計が1時間ずれていた | `--shift-hours -1` |
| 撮影時刻をメタデータから読む | `--use-metadata`（ffprobe が必要） |

既定はコピーです。**元の素材を残すほうが安全**なので、慣れるまでは `--move` を使わないでください。

## 撮影時刻の判定について

既定では**ファイルの更新時刻**を使います。カメラが書き込んだ時刻がそのまま残るので、
ほとんどの場合はこれで正しく振り分けられます。

- **カメラの時計を出発前に日本時間へ合わせておいてください。** ここがずれると全部ずれます
- ずれてしまった場合は `--shift-hours` で補正できます（`--dry-run` で確認してから実行）
- 行程の日付に当てはまらないものは `00_未分類/` に入り、実行後に一覧で表示されます

## 合格ラインの確認

実行すると映像素材の本数が出ます。`企画書.md` の合格ライン（150本以上）を満たしているか、
その場で分かります。

```
コピー: 203 本  /  映像素材: 187 本
合格ライン（150本以上）を満たしています。
```

本数が足りない場合、`--target` で基準を変えられます。
