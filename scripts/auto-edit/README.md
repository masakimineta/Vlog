# autoedit — 素材と台本から Vlog を自動編集する

撮影した素材フォルダと台本を渡すと、カットを選び、B ロールを差し込み、字幕を焼き、
BGM を重ねた MP4 を書き出します。

```bash
python -m autoedit auto ~/Movies/Vlog素材/EP001-京都の朝さんぽ \
  --script ../../episodes/EP001-京都の朝さんぽ/台本.md \
  --bgm ../../assets/BGM/morning.mp3 \
  -o ~/Desktop/EP001-v1.mp4
```

## 何をしてくれるか

1. **素材を解析** — Whisper で全クリップを文字起こしし、喋りの有無で
   「喋りクリップ」と「風景クリップ」に自動で振り分ける
2. **台本と照合** — 台本の各パートに対応する区間を素材から探す。撮り直した箇所は
   一致率の高いテイクが選ばれる
3. **無音を詰める** — 発話の合間の長い間を落とす
4. **B ロールを被せる** — 台本の `[映像] B001 ...` に従って、喋りの音声を残したまま
   映像だけ差し替える
5. **字幕** — 文字起こしをそのまま字幕にして焼き込む（手打ち不要）
6. **BGM** — 喋りの下では自動で音量を下げ、頭と尻でフェード
7. **音量を揃えて書き出す** — 全体を -14 LUFS（YouTube の基準）に調整

## できないこと

- **BGM の生成** — 曲は自分で用意して `--bgm` で渡す必要があります。Claude は音楽を
  聴いて雰囲気を判断できないので、「明るい曲を選んで」ではなく曲そのものを指定します
- **感覚的な判断** — 「このテイクのほうが表情がいい」「ここは間を残したい」は分かりません
- **カラーグレーディング** — 色の調整はしません

出てくるのは「そのまま公開できなくはないが、こだわるなら手を入れたくなる」水準です。

```bash
python -m unittest discover tests
```

## 使い方

### 通しで実行する

```bash
python -m autoedit auto <素材フォルダ> --script <台本.md> --bgm <BGM> -o <出力.mp4>
```

途中経過として `出力.analysis.json`（解析結果）と `出力.plan.json`（編集プラン）が
残ります。同じ素材で作り直すときは、この解析結果を再利用すると文字起こしを省けます。

### 段階ごとに実行する

プランを確認してから書き出したい場合はこちら。

```bash
# 1. 解析（時間がかかるのはここ）
python -m autoedit scan <素材フォルダ> -o analysis.json

# 2. 編集プランを作る（内容を確認できる）
python -m autoedit plan -a analysis.json -s 台本.md -b bgm.mp3 -o plan.json

# 3. 書き出す
python -m autoedit render -p plan.json -o 完成.mp4
```

`plan.json` は普通の JSON なので、**気に入らない箇所は手で直してから render できます。**
カットの長さを変える、使うクリップを差し替える、といった調整はここでやるのが早いです。

### 台本がない場合

`--script` を省くと、ファイル名順に喋りクリップをつなぎ、間に風景クリップを挟みます。
下書きを見るには十分です。

### 喋りがない動画（風景 + BGM だけ）

`--no-transcribe` を付けると文字起こしを飛ばし、全クリップを風景として扱います。
台本で長さを指定すると、その順・その尺で並びます。

```markdown
## オープニング

[映像] B001 空 5秒 / B002 川面 4秒
```

## 台本の書き方

`templates/台本.md` の記法をそのまま読み取ります。

| 記法 | 意味 |
|------|------|
| `## 見出し` | セクション。チャプターにもなる |
| `> 台詞` | 喋る内容。**文字起こしと照合してカットを決める** |
| `- 要点` | 話す要点のメモ。ゆるめに照合する |
| `[映像] B001 説明` | そのパートで使う映像。カット番号でファイルを引く |
| `[映像] B001 説明 5秒` | 長さを指定する |
| `[テロップ] 文字` | 画面に出す文字 |

- カット番号（`A001` / `B012`）は `docs/命名規則.md` のファイル名から自動で拾われます
- `[映像]` があって喋りがないセクションは、風景パートとして扱われます
- `表記ルール` `使わなかったが残しておくネタ` といった見出しは本編に含まれません

### 照合がうまくいかないとき

台詞どおりに喋っていないと一致率が下がり、そのパートが飛ばされます。実行時に

```
■ 注意
   - [導入] 対応する音声が見つかりませんでした: 去年の今ごろ、僕は…
```

と出るので、次のいずれかで対応してください。

- 台本を実際に喋った内容に近づける
- `--match-threshold 0.4` のようにしきい値を下げる（既定は 0.55）
- そのパートを `-` の要点メモ形式に変える（自動でゆるく照合されます）

## 設定

既定値を変えたいときは JSON を用意して `--config` で渡します。

```json
{
  "width": 3840,
  "height": 2160,
  "speaker_head_seconds": 2.0,
  "broll_seconds": 5.0,
  "bgm_gain_db": -10.0,
  "burn_subtitles": false
}
```

よく触るもの:

| 項目 | 既定 | 意味 |
|------|------|------|
| `width` / `height` / `fps` | 1920×1080 / 30 | 書き出しサイズ。4K で出すなら 3840×2160 |
| `whisper_model` | `small` | `medium` にすると精度は上がるが遅くなる |
| `match_threshold` | 0.55 | 台本と音声の一致率のしきい値 |
| `speaker_head_seconds` | 3.0 | B ロールを被せる前に話者を映す秒数。0 にすると全面 B ロール |
| `max_gap_seconds` | 0.6 | これを超える無音は詰める |
| `bgm_gain_db` | -8.0 | BGM の音量 |
| `bgm_duck_db` | -12.0 | 喋りの下で BGM をどれだけ下げるか |
| `target_lufs` | -14.0 | 最終的な音量 |
| `subtitle_font` | OS 既定 | 字幕フォント（macOS: Hiragino Sans / Windows: Yu Gothic UI） |

## 制約と注意

- **手元の PC で実行してください。** クラウド上の Claude Code セッションには素材が
  ないため動きません
- **処理時間** — 文字起こしが大半を占めます。8 分の素材（元素材 30 分程度）で
  30 分〜1 時間が目安。GPU があれば大幅に速くなります
- **元素材は変更しません。** 読み取りのみで、書き込みは出力先だけです
- **フィラー除去は控えめです。** 区間の先頭・末尾の「えー」だけを落とします。
  文中まで削ると不自然に途切れるためです
