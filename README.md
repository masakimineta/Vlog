# Vlog 制作管理リポジトリ

Vlog の企画から公開までを 1 か所で管理するためのリポジトリです。
動画ファイルそのものは Git では管理せず、**企画・台本・撮影計画・編集メモ・公開情報**といったテキスト情報だけを追跡します。

## ディレクトリ構成

```
.
├── docs/                  # 制作の共通ルール
│   ├── 運用ガイド.md        # このリポジトリの使い方（まずここを読む）
│   ├── ワークフロー.md      # 企画〜公開までの流れ
│   ├── 命名規則.md          # ファイル・フォルダの命名ルール
│   ├── 撮影機材.md          # 機材と設定のメモ
│   └── 公開チェックリスト.md  # 公開前の最終確認
├── templates/             # 各ドキュメントの雛形
│   ├── 企画書.md
│   ├── 台本.md
│   ├── 撮影計画.md
│   ├── 編集メモ.md
│   └── 公開情報.md
├── episodes/              # エピソードごとの作業フォルダ
│   └── EP000-サンプル/      # 書き方の見本（記入済み）
├── assets/                # ロゴ・BGM リストなどの共通素材メモ
└── scripts/
    ├── new-episode.sh     # 新しいエピソードの雛形を作るスクリプト
    ├── auto-edit/         # 素材と台本から動画を自動編集するツール
    └── route-map/         # 行程からルート図のアニメーションを作るツール
```

## 使い方

具体的な運用手順は [`docs/運用ガイド.md`](docs/運用ガイド.md) にまとめています。
初めて使うときは、まずそちらの「最初に 1 回だけやる準備」を済ませてください。

### 1. 新しいエピソードを作る

```bash
./scripts/new-episode.sh 001 京都の朝さんぽ
```

`episodes/EP001-京都の朝さんぽ/` が作られ、`templates/` の雛形一式がコピーされます。

手動で作る場合は `templates/` の中身を新しいフォルダにコピーしてください。

### 2. 企画・台本を書く

`企画書.md` → `台本.md` → `撮影計画.md` の順に埋めていきます。
記入例は [`episodes/EP000-サンプル/`](episodes/EP000-サンプル/) を参照してください。

### 3. 撮影・編集

撮影した素材は [`docs/命名規則.md`](docs/命名規則.md) に従って外部ストレージに保存し、
リポジトリには `編集メモ.md` に構成やカット位置を記録します。

### 4. 公開

`公開情報.md`（タイトル・概要欄・タグ）を仕上げ、
[`docs/公開チェックリスト.md`](docs/公開チェックリスト.md) で確認してから公開します。

## 自動編集

編集ソフトを使わずに、素材と台本から MP4 を書き出すこともできます。

```bash
cd scripts/auto-edit
python -m autoedit auto ~/Movies/Vlog素材/EP001-京都の朝さんぽ \
  --script ../../episodes/EP001-京都の朝さんぽ/台本.md \
  --bgm ../../assets/BGM/morning.mp3 \
  -o ~/Desktop/EP001-v1.mp4
```

カット選び・B ロールの差し込み・字幕・BGM・音量調整までを自動で行います。
BGM そのものは生成できないため、曲は自分で用意します。
セットアップと詳しい使い方は [`scripts/auto-edit/README.md`](scripts/auto-edit/README.md) を参照してください。

**手元の PC で実行する必要があります**（クラウド上のセッションには素材がないため）。

## ルート図のアニメーション

旅の行程を、地図の上に線が 1 本ずつ伸びていくアニメーションにできます。

```bash
cd scripts/route-map
python -m routemap --size 4k -o ~/Desktop/EP002-routemap.mp4
```

行程は `scripts/route-map/routemap/itinerary.py` に書きます。
**遅延などで行程が変わったら、そのファイルを直して実行し直すだけ**です。
詳しくは [`scripts/route-map/README.md`](scripts/route-map/README.md) を参照してください。

## 動画ファイルの扱い

動画・音声・RAW 画像は `.gitignore` で除外しています。
容量が大きくリポジトリを圧迫するため、素材は外部ストレージ（外付け SSD / クラウド）で管理し、
その保存場所を各エピソードの `撮影計画.md` に記録してください。

リポジトリ側と外部ストレージ側で**エピソードのフォルダ名を揃える**のが基本ルールです。

```
リポジトリ                          外付け SSD
episodes/EP001-京都の朝さんぽ/  ←→  Vlog素材/EP001-京都の朝さんぽ/
```

具体的な手順は [`docs/運用ガイド.md`](docs/運用ガイド.md) を参照してください。
